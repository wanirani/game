# 블러드 녹턴 : 악마성 연대기 (BLOOD NOCTURNE)

핏빛 달이 뜨는 밤, 안개 속에서 되살아난 드라큘라의 성으로 들어가는 **2D 횡스크롤 고딕 액션 게임**입니다.
「악마성 드라큘라」 계열의 탐험·채찍 액션에 아케이드식 점수·콤보·타격감, RPG식 성장·장비·강화를 더했습니다.
브라우저만 있으면 PC와 모바일에서 모두 플레이할 수 있습니다.

## 바로 실행

```bash
node tools/serve.mjs 8080      # http://localhost:8080 접속
```

빌드 과정이 없는 순수 HTML5 Canvas + ES 모듈 구조라서, 정적 호스팅(GitHub Pages, Netlify 등)에 폴더째 올리면 그대로 실행됩니다.
한 번 접속하면 서비스 워커가 파일을 캐시하므로 이후에는 오프라인에서도 실행되고, 모바일에서 「홈 화면에 추가」로 앱처럼 쓸 수 있습니다.

## 조작

| 동작 | 키보드 | 게임패드 | 모바일 |
|---|---|---|---|
| 이동 | ← → (↑ 문·NPC, ↓ 웅크리기) | 방향 패드 / 왼쪽 스틱 | 왼쪽 가상 스틱 |
| 점프 / 이단 점프 | Z, Space | A | 점프 |
| 공격 (연타 콤보, 누르고 있다 떼면 모아베기) | X | B, X | 공격 |
| 대시 (무적) | C, Shift | LT | 대시 |
| 보조무기 (하트 소모) | A | Y | 보조 |
| 스킬 1 / 2, 스킬 페이지 전환 | S / D, Q | LB / RB | S1 / S2, ⇄ |
| 필살기 (게이지 100%) | F | RT | 필살 |
| 메뉴 / 일시정지 | Esc, Enter | Start | Ⅱ |

- 방향 + 공격: ↑+공격은 띄우기, 공중에서 ↓+공격은 내려찍기, 대시 중 공격은 돌진 베기입니다.
- 비전서로 익힌 **커맨드 기술**도 있습니다. 예: ↓↘→+공격 = 파동참, →↓↘+공격 = 승천격.
- 타이틀에서 ↑↑↓↓←→←→ X Z를 입력하면 숨은 헌터가 모두 해금됩니다.

## 그래픽 제작 방식

- **클링(Kling)**: 스테이지·장소 배경 21장, 캐릭터·NPC·보스 초상화 26장, 타일 텍스처 13장(이어 붙여도 경계가 보이지 않게 가공), 스토리 이벤트 CG 14장. 프롬프트와 생성 ID는 `tools/kling/manifest.json`에 있습니다.
- **블렌더(Blender, bpy)**: 아이템 아이콘 103종, 스테이지 소품(촛대·관·보물상자·문 등), 스테이지별 배경 장식 50종을 절차적 3D 모델링 후 Cycles로 렌더했습니다. 스크립트는 `tools/blender/`에 있습니다.
- **절차적 렌더링**: 캐릭터·적·보스는 뼈대(스켈레톤) 기반 벡터 애니메이션으로 그립니다. 장비와 직업이 바뀌면 외형이 바로 반영됩니다. 망토·머리카락·스카프는 물리 시뮬레이션(Verlet)으로 흔들립니다.

2D를 택한 이유는 모바일 성능, 악마성 원작의 조작감, 그리고 장비·직업에 따른 외형 변화를 매끄럽게 표현하기 위해서입니다.
카메라는 진행 방향을 앞질러 보여 주는 3인칭 추적 방식이며, 콤보 마무리와 보스전에서는 줌이 연출됩니다.

## 폴더 구조

```
index.html  css/  sw.js  manifest.webmanifest
src/core     엔진 코어 (루프·장면, 입력·터치 패드, 카메라, 물리, 파티클, 조명, 저장, UI, 오디오)
src/game     게임 로직 (월드, 플레이어, 적·AI, 보스, 전투, 투사체, 아이템·강화, 스킬, 퀘스트, 성장)
src/render   절차적 렌더러 (캐릭터, 적, HUD, 배경, 타일, 아이콘)
src/data     데이터 (캐릭터, 직업, 스킬, 아이템, 적, 보스, 스테이지·맵, 스토리, 퀘스트, 음악)
src/scenes   화면 (타이틀, 캐릭터 선택, 마을, 월드맵, 상점, 대장간, 성당, 메뉴, 여관 미니게임, 아케이드, 엔딩)
assets       bg · portraits · tex · cg (클링) / icons · props (블렌더) / ui
tools        개발 서버, 스모크·통합 테스트, 맵 검증기, 밸런스 시뮬레이터, 블렌더·클링 파이프라인
docs/ARCHITECTURE.md   모듈 간 계약서 (스키마, ID 목록, API)
```

## 개발 도구

```bash
node tools/validate_maps.mjs            # 모든 맵 문법·도달 가능성 검사
node tools/balance.mjs normal kael      # 스테이지별 레벨·타수·피해 비율 시뮬레이션
node tools/integration.mjs              # 모든 화면·스테이지·보스방 자동 실행 + 오류 수집
node tools/smoke.mjs --url "index.html?scene=stage&stage=s05&room=r2&char=sera&debug"
```

주소 뒤에 `?scene=stage&stage=s03&char=lia&room=r2`를 붙이면 원하는 스테이지로 바로 들어갑니다. `&debug`를 추가하면 히트박스와 FPS가 표시됩니다.
