## 1. 장비 점수 (모든 기능의 바탕)

- 새 파일 `src/game/gear_score.js`: `gearScore(hero, inst, {classId})` → 숫자 하나, `gearDelta(hero, inst)` → `{score, stats:[{stat, from, to}]}`.
- 점수 = 그 영웅·직업이 실제로 쓰는 능력치 가중합. 가중치는 `src/game/stats.js` 의 최종 능력치 계산을 그대로 거쳐 "장착했을 때 - 지금" 차이로 낸다(따로 공식을 만들지 않는다 → 직업 특성·세트·강화·추가 옵션이 자동 반영).
- 영웅별 가중치 표(공격형/방어형)는 `src/data/gear_weights.js` — 직업 계열(`classes.js` 역할)로 고른다. 사용자가 옵션에서 "공격 우선/균형/생존 우선" 셋 중 고를 수 있게.
- 무기는 직업이 쓸 수 없는 무기 종류(`WTYPES`)면 점수 없음(비교 대상 아님).
- 고유·신화·세트 효과처럼 숫자로 안 잡히는 효과는 점수에 "+효과" 표시만 붙이고 자동 장착에서 **빼지 않는다**(사용자가 고른 것으로 존중).

## 2. 최적 장착 (자동 장착)

- 장비 탭 하단 버튼 「최적 장착」 (패드: Y / 키보드: R / 터치: 버튼). 누르면 6칸을 각각 가장 점수 높은 후보로 바꾸는 **미리보기**를 먼저 보여 준다(칸별 바뀌는 것·총 증감) → 확인해야 적용.
- 규칙: 잠긴 장비는 그 칸을 고정으로 본다(빼지 않음). 고유·신화·세트 장비가 끼워져 있으면 그 칸은 기본 고정(옵션으로 풀 수 있음). 장신구 2칸은 중복 없이 상위 2개. 다른 영웅이 끼고 있는 장비는 후보에서 뺀다. 레벨 제한(`lvReq`) 미달 제외.
- 세트 보너스: 칸별 탐욕 선택 뒤, 세트가 깨지는 경우 "세트 유지" 안과 점수를 견줘 더 높은 쪽(세트 2·4피스 효과는 stats.js 결과로 비교).
- 마을 「파티」 화면에서도 「모두 최적 장착」 (영웅 7명 차례로, 공유 가방 경합은 지금 선택한 영웅 먼저).
- 되돌리기: 적용 직후 5초 「되돌리기」 토스트.

## 3. 획득 즉시 비교

- 장비를 주우면 획득 토스트 옆에 지금 영웅 기준 ▲/▼/= 와 점수 차를 보여 준다(`game.js` 토스트 · `feel_hud` 줄과 겹치지 않게 `hud_layout` 등록).
- 더 좋은 장비(▲)를 주웠을 때: 일시정지 메뉴 없이 「바로 장착」 가능 — 패드 길게 누르기(↑ 0.4초) / 터치 토스트 탭 / 키보드 E. 전투 중에는 표시만, 장착은 안전 지대(적 없음 2초)에서.
- 가방 탭: 장비 칸 모서리에 ▲(지금 영웅에게 더 좋음) 녹색 화살표, 다른 영웅에게 더 좋으면 그 영웅 얼굴 작은 표시. 상세 창에 "착용 중인 ○○과 비교" 표를 장비 탭과 같은 모양으로 넣는다(가방·상점·대장간·보물상자 결과 화면 공통 컴포넌트 `src/scenes/menu/gear_compare.js`).
- 무기 비교 표에는 공격력·공격 속도·치명·속성 외에 **초당 피해 어림**(`balance.mjs` 의 DPS 식 재사용)을 한 줄로.

## 4. 자동 처분

- 옵션 「게임 → 장비」 페이지 신설(`src/scenes/front/options.js`): 
  - 「자동 처분」 끔 / 판매 / 분해(대장간 재료) — 기본 **끔**.
  - 「처분 기준」 일반 이하 / 고급 이하 / 희귀 이하 (영웅 이상은 고를 수 없음).
  - 「예외」 강화된 장비 · 지금 영웅보다 좋은 장비(▲) · 다른 영웅에게 좋은 장비 · 고유/세트 — 모두 기본 켬(=처분 안 함).
- 처분 시점: 스테이지 끝 결과 화면(`results.js`)에서 한 번에 — 전투 중 줍는 순간 사라지게 하지 않는다. 결과 화면에 "자동 판매 12개 · +3,450 G" 한 줄 + 펼치면 목록.
- 되사기: 마을 상점 「되사기」 탭에 최근 자동 처분 30개를 판 값 그대로 다시 살 수 있게 보관(세이브에 저장, 스테이지 3번 지나면 사라짐).
- 수동 일괄: 가방 탭 「일괄 처분」 버튼 → 기준 고르기 → 미리보기(개수·골드) → 확인. 기존 `sellJunk` 를 기준·예외를 받도록 넓혀 재사용.
- 잠금 장비, 장착 중 장비, 퀘스트·중요 물품, 다시 얻을 수 없는 보상(`inventory.js` 보관함 대상)은 어떤 경우에도 처분하지 않는다.

## 5. 그 밖의 편의 (같은 묶음)

- 가방 필터: 칸(무기/방어구/장신구/소모품/재료) · 희귀도 이상 · "지금 영웅이 쓸 수 있는 것만".
- 새로 얻은 장비 NEW 표시(한 번 보면 사라짐).
- 가방 가득 참 경고를 스테이지 입장 전에(남은 칸 5 이하) + 그 자리에서 「일괄 처분」 바로가기.
- 대장간 강화 화면에서도 비교 컴포넌트 사용(강화 전/후).

## 6. 세이브·호환

- 설정은 settings 스키마(`save.js` settings v2)에 `gear: { autoDispose: 'off'|'sell'|'salvage', maxRarity: 0..2, keep: {...}, weights: 'atk'|'bal'|'def' }` 추가, 없으면 기본값.
- 되사기 목록은 세이브 `state.buyback[]` (최대 30). 옛 앱이 열면 무시(오류 없음).
