# 온라인 기능 명세 (리더보드 · 일일 도전 · 고스트)

서버(netlify/lib)와 클라이언트(src)가 함께 따르는 계약. 바꾸려면 이 문서를 먼저 고친다.

## 0. 원칙

- 기록 제출은 **로그인한 계정만** 할 수 있다. 게스트는 기기 안 기록(명예의 전당)만 쓴다.
- 순위표에는 로그인 아이디를 **절대** 보이지 않는다. 계정마다 공개 별명 `nick` 을 따로 둔다.
  - 처음 제출할 때 없으면 `헌터#1234` 형태로 자동으로 만든다.
  - 2~12자 한글·영문·숫자·`_`, 금칙어 목록으로 거른다. 별명이 겹치면 `#숫자` 를 붙인다.
- 모든 쓰기는 기존 요청 제한(`netlify/lib/ratelimit.mts`)을 쓴다. 저장소는 기존 runtime store factory 로 만든다(시험은 메모리 저장소).
- 서버는 제출값이 말이 되는지만 검사한다(아래 §3). 완전한 부정 방지는 목표가 아니다.

## 1. 보드 ID

| 종류 | 보드 ID | 순위 기준 |
|---|---|---|
| 보스 러시 | `bossrush:<course>:<diff>` | `time`(ms) 작을수록 위 |
| 서바이벌 | `survival:<diff>` | `wave` 클수록 위, 같으면 `score` 큰 쪽 |
| 스테이지 연습 | `practice:<stageId>:<diff>` | `time`(ms) 작을수록 위, 같으면 `score` 큰 쪽 |
| 일일 도전 | `daily:<YYYYMMDD>` | `time`(ms) 작을수록 위 |

- `<course>`: arcade.js `COURSES` 의 인덱스. `<diff>`: difficulty id. `<stageId>`: `s01`…`s20`.
- 일일 도전 날짜는 **한국 시간(UTC+9)** 기준이다.

## 2. API

인증은 기존 계정 API 와 같은 `Authorization: Bearer <token>` 이다.

### 2.1 런 시작
`POST /api/runs` (인증 필요)
- 요청: `{ board }`
- 응답: `{ run, seed, ts }`
  - `run` 은 서버가 서명한 불투명 문자열(보드·계정·시작 시각 포함, HMAC, 6시간 유효)이다.
  - `seed` 는 32비트 정수다(일일 도전은 그날 시드, 나머지는 무작위).

### 2.2 런 제출
`POST /api/runs/finish` (인증 필요, 본문 ≤ 48 KB)
- 요청: `{ run, result, ghost? }`
  - `result`: `{ time, score, wave?, rank?, hero, cls, level, deaths? }`
  - `ghost`: base64 문자열, 24 KB 이하. 형식은 클라이언트가 정하고 서버는 열어 보지 않는다.
- 응답: `{ ok: true, best, rank, total, entry }`
  - `best`: 이번 기록이 그 계정의 최고 기록을 갱신했는가.
  - `rank`: 갱신 뒤 순위(1부터), 100위 밖이면 `null`.
- 계정당 보드마다 **최고 기록 1개**만 남긴다.
- 고스트는 갱신된 최고 기록이 **상위 20위 안**일 때만 저장한다. 밀려나면 지운다.

### 2.3 순위표
`GET /api/boards/<board>?limit=50` (공개, limit ≤ 100)
- 응답: `{ board, total, entries: [{ rank, nick, time, score, wave?, hero, cls, level, date, ghost: bool }], me? }`
- 인증 헤더가 있으면 `me: { rank, time, score, wave? }` 를 함께 준다.
- `Cache-Control: public, max-age=30`. 인증한 요청은 `no-store`.

### 2.4 고스트
`GET /api/ghosts/<board>/<rank>` (공개)
- 응답: `{ nick, time, hero, cls, data }` (`data` = 제출한 base64), 없으면 404.

### 2.5 일일 도전
`GET /api/daily` (공개)
- 응답: `{ date, seed, stageId, diff, hero, cls, preset, mods: [..], board }`
- 날짜에서 결정적으로 만든다.
  - 같은 날이면 누구나 같은 값을 받는다.
  - 서버 비밀값(HMAC 키)을 섞어 미리 알 수 없게 한다.
  - 키는 `AUTH_PEPPER` 가 있으면 그것을, 없으면 고정 문자열을 쓴다.
- `mods`: 아래 목록에서 1~2개.
  - `hp_x1.5` (적 체력 1.5배)
  - `no_potion` (물약 금지)
  - `glass` (받는 피해 2배, 주는 피해 1.3배)
  - `haste` (적 속도 1.25배)
  - `dark` (시야 좁음)
  - `no_sub` (보조 무기 금지)

### 2.6 별명
`PUT /api/profile/nick` (인증 필요)
- 요청: `{ nick }`
- 응답: `{ nick }`
- `GET /api/auth/me` 응답에 `nick` 을 더한다.

## 3. 서버 검사

- `run` 서명·만료·보드 일치·계정 일치. 같은 `run` 으로는 한 번만 제출할 수 있다.
- 걸린 실제 시간(제출 시각 − 시작 시각) ≥ `result.time` × 0.9 − 3초.
- 보드별 상한·하한
  - 보스 러시·연습·일일: `time` 은 5초 이상 2시간 이하.
  - 서바이벌: `wave` 는 1~999.
  - `level` 1~99, `score` 0~99,999,999.
  - `hero`·`cls` 는 데이터에 있는 id.
- 계정당 제출은 1분에 6번, 하루에 300번까지.

## 4. 클라이언트

- **런 흐름**
  - 아케이드 모드나 일일 도전을 시작할 때 로그인 상태면 `POST /api/runs` 를 비동기로 호출한다. 실패해도 게임은 그대로 한다.
  - 끝나면 결과 화면에서 제출하고 순위를 보여 준다.
  - 오프라인이면 결과를 기기에 잠시 두었다가 다음 접속 때 보낸다. 단, `run` 은 6시간 안에만 유효하다.
- **명예의 전당**: '기기 / 온라인' 탭을 둔다. 온라인 탭은 보드 선택(종류·코스·난이도·스테이지·오늘의 도전)과 상위 50명, 내 순위를 보여 준다.
- **일일 도전**: 아케이드 메뉴에 '오늘의 도전' 카드를 둔다.
  - 그날 정해진 스테이지·헌터·규칙으로 연습 모드를 돌린다.
  - 같은 날 몇 번이든 할 수 있고, 최고 기록만 남는다.
- **고스트**
  - 연습·일일 도전 중 영웅 상태를 10Hz 로 기록한다(방, x, y, 방향, 동작).
  - 시작 화면에서 '고스트: 끔 / 1위 / 내 최고' 를 고르면 반투명 실루엣이 같은 경로를 달린다.
  - 고스트는 충돌하지 않는다.
- **로그인하지 않았을 때**: 온라인 탭과 오늘의 도전 순위표는 볼 수 있다. 제출 자리에는 '로그인하면 순위에 오를 수 있어요' 를 띄운다.
