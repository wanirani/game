# 일본 게임풍 캐릭터 · 부드러운 모션 · 360° 회전 · 고급 효과음 (ANIME-MOTION-SFX) — 설계

상태: **대기** (다음 작업 — 2026-10-11 일요일 재개분에 포함)
요청: 사용자 2026-10-09
1. 게임 안에서 움직이는 캐릭터가 서구풍이라 이질적 → 일본 게임 스타일로.

3. 상태 화면 캐릭터 회전 → 각도를 훨씬 많이, 진짜 360°.
4. BGM 은 괜찮음, 효과음이 미디 느낌 → 고급스럽게.

## 1. 일본 게임풍 캐릭터 (요청 1)

**방향**: 대화 초상화와 같은 "고딕 애니 + 셀 셰이딩" — 또렷한 외곽선, 2~3단 명암, 큰 눈·작은 코의 얼굴 비율, 머리카락 덩어리 하이라이트, 7~7.5등신(전투 화면에서 머리 크기 약간 키움). 색은 지금 직업 색 체계 유지.

- 원화: Kling 이미지 생성(초상화 Phase F 와 같은 프롬프트 계열 + 각 영웅 `keyart_<hero>` 를 참조 이미지로) → 직업별 **측면 전신 원화 1장 + 부위 분리용 '파츠 시트' 1장**.
- 범위: 퍼펫 49벌 전부 교체. 초월 28 · 비전 7 은 지금처럼 기본 퍼펫 + 색·장식 겹침(`hero_puppet.js` 의 asc 장식) 유지.
- 순서: **시범 1벌(카엘 헌터)** → 게임 화면 스크린샷을 사용자에게 보냄 → 영웅별 7벌씩 진행(영웅 하나 끝날 때마다 `tools/puppet/review.mjs` + 게임 안 확인).
- 파이프라인 재사용: `tools/puppet/ingest.py → build_rig.py → build_turn.py → build_all.py`. 부위 경계·관절 위치는 새 원화 기준으로 다시 잡음(`tools/puppet/rigs/`).
- NPC 퍼펫(`assets/puppets/npc`)도 같은 그림체로(마을에서 섞여 보이지 않게) — 2순위.
- Kling 어림: 원화·파츠 시트·재시도 포함 직업당 약 12~16 크레딧 × 49 ≈ 600~800 크레딧 (잔액 약 4,500).

## 2. 부드럽고 실감나는 모션 (요청 2)

컷아웃만으로는 한계 → **"퍼펫 + 핵심 동작 그림 프레임" 혼합**.

### 2.1 퍼펫 자체 개선 (모든 동작)
- 판 회전 대신 **메시 변형**: 몸통·팔·다리 부위를 삼각 메시로 나눠 관절 근처를 휘게(2D 스키닝, 가중치 2본). 이음매 사라짐, 팔꿈치·무릎이 자연스럽게 굽음. `hero_puppet.js` 에 메시 그리기 경로 추가(Canvas `drawImage` 삼각형 클리핑 — 저사양은 지금 방식 유지).
- **보조 움직임**: 머리카락·망토·치맛자락·무기 끈에 스프링 체인(지금 망토 체인을 머리카락·옷자락까지 확장), 착지 때 무게 실림, 달리기 상하 흔들림·몸 기울기, 방향 전환 시 미끄러짐 1~2프레임.
- **연출 프레임**: 공격 휘두름에 스미어(번진 잔상) 프레임, 시작·끝 정지 프레임(앤티시페이션/팔로스루), 이징 곡선을 직선 보간에서 곡선으로.
- 갱신: 그리기 60fps 보간(지금 논리 프레임 사이 보간 확인, 30fps 기기에서도 끊김 없게).

### 2.2 핵심 동작 그림 프레임 (영웅별 공통 몸)
- 달리기 순환 8프레임, 대시 4, 점프(도약·정점·낙하·착지) 6, 기본 공격 3타 각 5~6, 피격 3, 사망 6 — **Kling 영상(image_to_video, 측면 고정 카메라) → 프레임 추출 → 배경 제거 → 정리**.
- 직업마다 다 만들지 않고 영웅 몸 공통 프레임 + 직업 의상·무기는 퍼펫 부위로 덧그림(머리·무기·망토는 퍼펫, 몸 실루엣은 프레임).
- 어림: 영웅 7 × 동작 6 클립 × 약 35 크레딧 ≈ 1,500 크레딧. 시범(카엘 달리기·공격) 먼저 하고 결과가 퍼펫 개선(2.1)보다 확실히 나을 때만 확대.

### 2.3 탈것
- 말·늑대 계열: 다리 4개 각각 보행 순환(걷기 4박·질주 3박 갤럽), 머리·목 흔들림, 갈기·꼬리 스프링, 착지 충격, 속도에 따라 보폭·몸 기울기.
- 날짐승(와이번·박쥐·그리핀): 날갯짓 곡선(내려칠 때 빠르게, 올릴 때 느리게), 몸이 날갯짓에 맞춰 오르내림.
- 기수 동기화: 탈것 등뼈 위치를 따라 기수 엉덩이가 오르내리고 상체가 반대로 받아 줌(`mount_rig.seatOf` 확장).
- 탈것 원화도 1번과 같은 그림체로 다시 그림(11종) — 약 150 크레딧.

## 3. 진짜 360° 회전 (요청 3)

- 각도: **16방향(22.5° 간격)** — 정면·등 포함. Kling 으로 영웅·직업별 "턴어라운드 시트"(8방향 한 장) 생성 → 8방향 확보, 좌우 대칭인 각도는 뒤집고 비대칭 부위(무기·장식·머리 가르마)만 따로 바로잡아 16방향.
- 각도 사이: 이웃 두 장을 부위별로 **겹쳐 바꾸기(크로스페이드) + 실루엣 폭 보간** → 끌 때 끊김 없이 돎. 손가락/스틱 놓으면 관성으로 돌다가 멈춤, 두 번 탭하면 정면으로.
- 장비 바꾸면 회전 중에도 즉시 반영(지금 `hero_view.js` 계약 유지), 확대(핀치·휠) 1.0~1.6배.
- 파일: 직업당 `turn16.webp` (ui 해상도, 칸 16개 아틀라스) — 옛 `turn.webp` 6장 대체. 용량은 2.1/1번 교체로 확보.
- 시험: `tools/qa/turntable.mjs` 를 16방향·관성·더블탭·핀치로 확장.

## 4. 고급 효과음 (요청 4)

- 원칙: **합성음 단독 재생을 없앤다**. 모든 효과음을 녹음 샘플 기반 + 층 쌓기(타격 순간음 + 몸통음 + 꼬리)로.
- 소재: (1) 로열티 없는 게임 오디오 묶음(예: Sonniss GDC Game Audio Bundle — 게임 포함·상업 이용 허용, 재배포는 게임 안에서만) 중 고딕 판타지에 맞는 것 고르기, (2) 부족한 것은 오디오 생성 도구(연결되어 있으면)로, (3) 라이선스는 `assets/audio/CREDITS.md` 에 하나하나 기록 — 출처가 불명확한 소재는 쓰지 않음.
- 오프라인 가공(`tools/audio/` 신규, Python): 층 합성, EQ, 가벼운 새츄레이션, 라우드니스 맞춤(-16 LUFS 효과음 기준), 짧은 꼬리 페이드.
- 실행 중: 소리마다 변형 3~5개 + 피치·볼륨 미세 무작위(같은 소리 연타 방지), 화면 위치에 따른 좌우 팬, 장소별 잔향(성당·동굴·지하수로 — 짧은 임펄스 응답 컨볼루션, 저사양은 끔), 효과음 버스 컴프레서·리미터, 큰 타격 때 BGM 살짝 눌러 주기(덕킹).
- 우선순위: 타격(무기 재질별: 베기·찌르기·둔기·마법), 발소리(바닥 재질 4종), 궁극기·각성, UI(메뉴 이동·확인·장착·획득·레벨업), 적 피격·사망, 탈것(말발굽·날갯짓).
- 용량: 효과음 예산 3 MB(지금 0.86 MB) 안에서. 넘으면 예산을 올리고 기록.
- 시험: `tools/test_sfx.mjs` 확장(모든 SFX 이름이 샘플을 가짐, 합성 단독 0건, 라우드니스 범위), 청취용 `tools/gallery_audio.html` 갱신.
