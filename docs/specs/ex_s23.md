## 0. 왜 빅터인가

s22 가 리아를 썼고(ex_s22.md §0: 카엘·브란·아젤은 1부에서 매듭, 이졸데는 s21), 남은 둘 중 **빅터는 풀린 실마리가 0** 이다 — 기록물(lore) 한 장 없고, 이름 붙은 과거 인물도 없다. 세라는 엘리제(s04)·성녀 루미나(l25·l33·`npc_rook_ch16`)로 이미 매듭이 있다. 빅터의 줄은 모두 "현상금" 농담 뒤에 숨은 같은 상처를 가리킨다:

| 실마리 | 출처 |
|---|---|
| 빈칸 공고 — "현상금 공고 보고 왔는데, 액수 칸이 비어 있더군." | `story.js` prologue |
| 거울 — "현상금 없는 싸움이라. 그게 네 진짜 얼굴이냐?" / "현상금은 핑계였어. 나도 이제야 알았지." | `story_p2.js` s14_t1 |
| 악몽 — "괴물 사냥꾼 빅터 그림 — 현상금: 괴물", 광장의 사냥꾼들이 은탄환을 장전한다 | `story_p2b.js` s18_t1 |
| 겁 — "난 원래 겁이 많아서 익숙하거든." / "덜덜 떠는 꼴이 딱 첫 사냥 때의 나로군." | `story.js` s13_t1 · `story_p2.js` s17_t1 |
| 끝내 받지 않는 돈 — "현상금? …됐어." / "현상금은 한 푼도 없군. …뭐, 이 아침이면 됐어." | `ending_true` · `ending_p2` |

외전은 이것을 한 번에 묶는다: **빈칸 공고는 빅터의 스승, 늑대잡이 하겐의 버릇**("목숨값은 쏜 놈이 평생 갚는 거다")이다. 열다섯 살 첫 사냥에서 얼어붙은 빅터 대신 하겐이 늑대 인간에게 물렸고, 빅터는 건네받은 은탄을 끝내 쏘지 못했다. 하겐은 눈보라 속으로 사라져 **십오 년 동안 '은빛 늑대'로 괴물을 사냥하며** 북쪽 게시판에 빈칸 공고를 붙였다. 빅터가 현상금을 쫓은 것은 핑계였다 — 그는 빈칸을 찾아다녔다. 악몽의 '괴물'은 스승을 그렇게 만들었다고 믿는 빅터 자신이다.

## 4. 이야기

### 4.1 설정 (기존 문장과 맞춘 것)

- 때: 2부 엔딩 뒤 몇 주. 에슈빌에는 아직 눈이 없고 북쪽 산마루만 하얗다 — s22(첫서리)와 어느 쪽을 먼저 해도 어긋나지 않는다. 알베르토는 부르지 않는다("그해 겨울" 줄과 부딪히지 않게), 프롤로그의 빈칸 공고만 지난 일로 말한다. 레이븐은 나오지 않는다(`RVX` 없음 → 두 엔딩 모두 같은 대본).
- 하겐: 북쪽 설원의 늑대잡이(사십 년). 열 살 소매치기였던 빅터를 거두어 총을 가르쳤다. 규칙 둘 — "겁나는 걸 부끄러워하지 마라. 겁이 없는 놈부터 죽는다." / "현상금 칸은 비워 둬라. 목숨값은 쏜 놈이 평생 갚는 거다." 공고마다 늑대 발자국 낙인을 찍는다.
- 십오 년 전: 빅터(열다섯)의 첫 사냥 — 늑대 인간 앞에서 얼어붙은 빅터 대신 하겐이 물렸다. 보름달 전날 은탄 한 발을 건네며 "때가 되면 쏴라" — 빅터는 쏘지 못했고, 하겐은 눈보라 속으로 사라졌다. 그 뒤 북쪽 게시판의 빈칸 공고 자리에는 늘 '은빛 늑대'가 먼저 다녀갔다.
- 사건: 하겐은 이번 겨울을 넘기면 아침이 와도 사람으로 돌아오지 못한다. 그래서 마지막 공고를 낸다 — "수배 — 은빛 늑대 · 맡을 사냥꾼 — 빅터 그림 · 현상금 — (빈칸)". 반전(싸움 전): 사냥감은 하겐 자신. 반전(싸움 속, 50%): 달이 떠 늑대가 된다.
- 결말: 쓰러진 늑대가 새벽빛에 사람으로 돌아와 "제대로 맞혔다, 꼬마"를 남기고 숨을 거둔다 (싸움의 상처로, 처형이 아니다). 빅터는 은탄을 끝내 장전하지 않고 무덤의 모자 옆에 둔다. 비어 있던 액수 칸에 "평생"을 적는다. 그 뒤 북쪽의 빈칸 공고에는 빅터의 이름이 적힌다.
- 동행: 빅터가 플레이 중인 영웅이 아니면 `R('victor')` 동행 NPC, 빅터면 `ifChar('victor', …)` 본인 분기(H). 다른 영웅 반응은 `H({...})` 여섯 자리 + default (이졸데 포함 — `p2_done` 이면 늘 합류). 새 CG 없음. 배경 `bg('s10_spire')`(제목·고개·아웃트로) · `bg('inn')`(흑묘 여관).
- 모순 점검: 프롤로그 빈칸 공고(알베르토 — 이번에 정체가 밝혀진다) · s13 "겁이 많아서" · s14 거울 · s17 "첫 사냥 때의 나" · s18 악몽 전단 · 두 엔딩의 "현상금은 됐어" · 그레타의 "북쪽 설원 늑대 왕"(스콜 — 다른 늑대, 언급하지 않음) · 결투자 자미엘·그레이(여관 놀이 — 언급하지 않음). 아르겐·네메인은 말하지 않는다.
- 글꼴: §4.2·§3·§5 의 모든 새 문장을 `noto-sans-kr.woff2`·`hahmlet.woff2` 기본 cmap 으로 확인 — **빠진 글자 0** (`/tmp/claude-0/ex3_design/glyphcheck.py`, ngplus 와 같은 방법 — 처음 초안의 '쐈'·'랗'·'붐' 은 '쏘지 못했어'·'노란 불처럼'·'희미하게' 로 피했다). **'덫'·'띠'(탄띠)는 기본 글꼴에 없다** — 게임에 보이는 문자열(데이터·대본·코드 문자열)에는 '덫' 대신 '올가미'를 쓴다 (주석·문서·시험 이름은 괜찮다). 구현 중 문장을 바꾸면 `python3 tools/fonts/build_fonts.py --check`.
