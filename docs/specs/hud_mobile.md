# 꽉 찬 화면 · 모바일 RPG식 인터페이스 (HUD-FULL) — 설계

상태: **대기** (다음 작업 — 2026-10-11 일요일 재개분에 포함)
요청: 사용자 2026-10-09 — 갤럭시 폴드 8 을 펼쳐서 할 때 아래쪽이 검게 비어 있음. 비워 두지 말고 참고 캡처(모바일 MMORPG)처럼 인터페이스를 짜고, 조작·스킬·탑승 버튼을 그림으로 채울 것.

## 0. 지금 구조와 문제 (커밋 `224a738` 기준)

- 논리 화면 높이 540 고정, 너비 960~1280 (`src/core/game.js` `VIEW_H`, `MIN_VIEW_W`, `MAX_VIEW_W`). 화면이 16:9 보다 네모나면(폴드 펼침 약 1.1~1.35 : 1, 태블릿 4:3) 위아래가 남음.
- 남는 세로가 120 CSS px 이상이면 캔버스를 위로 붙이고 아래 띠에 터치 버튼 두 줄(`touchpad.js` `PAD_LAYOUT_BAND`) — 띠 바탕이 **검은색**이고 버튼은 원 + 선 그림(`hud.drawSkillGlyph`)뿐이라 휑함.
- 체력·스킬·지도 등 HUD 는 게임 화면(960×540) 안쪽에만 있음.

## 1. 목표 화면 (참고 캡처 구조)

화면 전체를 게임 세계로 채우고, 그 위에 인터페이스를 얹는다. 검은 띠 없음.

```
┌──────────────────────────────────────────────────────────────┐
│ ◎미니맵  [스테이지 이름]      골드 · 영혼석 · 열쇠    ⚙메뉴 아이콘 줄(배지) │
│  (원형)                                         ┌ 퀘스트 추적 ┐ │
│                                                 │ 주·보조 3줄  │ │
│              (게임 세계 — 영웅·동료 이름표)          └────────────┘ │
│                                                                │
│  [동료/각성 아이콘]                                 ( 스킬 원호 )    │
│                                                 궁극기(육각·빛)  │
│    ( 조이스틱 )      [HP ████████ 21,093] 전투력      스킬1 스킬2 …  │
│                     [물약][  ][  ][  ]  경험치 줄    [공격 큰 버튼]  │
│  [대화/감정]                               [탑승][자동][대상][교대]   │
└──────────────────────────────────────────────────────────────┘
```

## 2. 화면 채우기 — "세로 확장 시야"

- 16:9 보다 네모난 화면에서는 **논리 높이를 늘린다**: `viewH = clamp(960 / 화면비, 540, 760)`, 너비는 960 유지(가로 시야를 줄이지 않음 — 횡스크롤에서 앞을 보는 거리가 중요).
- 방(room)이 시야보다 낮으면: 카메라를 방 가운데에 두고 위아래는 그 스테이지의 배경 층(원경·안개·천장/바닥 장식 타일)을 늘려 채움 — 검은 칸 금지. `tiles.js`·배경 렌더러에 "확장 여백 채우기" 추가, 스테이지마다 위·아래 채움 규칙(`src/data/stages.js` 에 `padTop`/`padBottom` 테마).
- 보스방·컷신·대화 장면도 같은 규칙. 고정 960×540 을 가정한 화면(메뉴·상점 등 uiScale 장면)은 가운데 정렬 + 테마 배경으로 둘레를 채움.
- 저사양: 확장 여백은 정지 그림(스테이지별 한 장)으로.

## 3. HUD 배치 (화면비별 프리셋)

`src/render/hud_layout.js` 에 프리셋 3개: **wide**(16:9~21:9 휴대폰 — 지금 배치 다듬기), **fold**(1.1~1.5 : 1 — 폴드 펼침·태블릿), **tall**(세로 화면, 메뉴만). 프리셋은 안전 영역(펀치홀·제스처 바) 기준.

| 자리 | 내용 | 비고 |
|---|---|---|
| 왼쪽 위 | **원형 미니맵**(지금 방 + 이웃 방, 출구·상자·보스 표시, 누르면 지도) + 스테이지 이름 + 낮/밤·날씨 표시 | 새 `minimap.js`, 방 데이터에서 미리 구워 둠 |
| 가운데 위 | 골드 · 영혼석 · 열쇠 등 재화 | 숫자 줄임(2.55M) |
| 오른쪽 위 | 메뉴 아이콘 줄: 지도 · 가방(가방 찬 비율 %) · 퀘스트 · 업적 · 우편/알림 · 메뉴 — 새 소식은 빨간 점 | 누르면 해당 메뉴 탭 |
| 오른쪽 | **퀘스트 추적 창**(주 퀘스트 1 + 보조 2, 진행 수치, 누르면 길 안내 화살표) — 접기 가능 | `quests.js` 연동 |
| 오른쪽 세로 | 동료 · 소환수 · 길찾기 · 설정 작은 아이콘 | |
| 왼쪽 아래 | **떠다니는 조이스틱**(누른 자리에 생김, 바탕 원판 그림), 동료/각성 상태 아이콘, 이벤트 시계 | |
| 가운데 아래 | **큰 HP 줄**(숫자 표시) + 전투력, 경험치 줄, **빠른 칸 4~5개**(물약·보조무기 — 개수 표시, 길게 눌러 바꾸기) | |
| 오른쪽 아래 | **스킬 원호**: 큰 공격 버튼(지금 무기 그림) 둘레로 스킬 6칸(그림 아이콘 · 쿨타임 시계바늘 · 남은 초 · 자원 부족 회색) + 잠긴 칸 자물쇠 + 궁극기(육각 테, 준비되면 금빛 회전 빛) + 각성기 | 원호 배치는 엄지가 닿는 반경 안 |
| 맨 아래 줄 | 점프 · 대시 · **탑승(말 그림)** · 자동 전투 · 대상 고정 · 영웅 교대 · 막기 — 작은 원형 그림 버튼 | 탑승 가능할 때만 밝게 |
| 캐릭터 위 | 이름표 + 칭호(직업·초월 이름) + HP 줄(동료) | 겹치면 위로 쌓기 |

- 버튼은 모두 **그림**: 무기·스킬·탑승·물약 아이콘 이미지, 테두리 장식(고딕 금속 테), 누를 때 눌림·빛 효과, 쿨타임 원형 진행.
- 기존 편집기(`touchpad.openEditor`)로 위치·크기 옮기기는 그대로(프리셋마다 저장).
- 데스크톱·패드에서는 같은 그림 HUD 를 쓰되 조이스틱 숨김, 버튼에 키/패드 표시(`prompts.js`).

## 4. 그림 자원

- 스킬 아이콘: 모든 스킬(기본 직업·1차·2차·초월·비전 액티브, 궁극기·각성기)을 **그림 아이콘**으로 — Kling 으로 3×3 묶음 생성(한 장에 9개) 후 잘라 `assets/icons/skills/<skillId>.webp`(96 px + 48 px). 어림 150종 ÷ 9 ≈ 17장 × 재시도 → 약 100~150 크레딧.
- 버튼 테·조이스틱 원판·HUD 틀(미니맵 테, 퀘스트 창, HP 줄 틀): 고딕 금속·피빛 장식 한 벌(`assets/ui/hud/`), 9-slice 로 늘림.
- 지금 벡터 그림(`drawSkillGlyph`)은 그림을 못 받았을 때의 대체로 남김.
- 용량: 아이콘·틀 합쳐 3 MB 안. 그림 예산은 ANIME-MOTION-SFX 의 옛 퍼펫 교체로 확보.

## 5. 기기·시험

- 기기 표(`tools/qa/lib` 기기 목록)에 추가: **fold_open**(가로 약 1.32 : 1, 예: 1000×755 CSS), **fold_open_sq**(약 1.1 : 1), **fold_cover**(약 21:9), tablet 4:3. 실제 폴드 8 해상도는 사용자 캡처(2000×1510)를 기준으로 맞춤.
- `tools/test_hud_layout.mjs`: 프리셋별 겹침 0, 버튼 최소 44 px·간격 12 px, 엄지 반경, 안전 영역 침범 0, 검은 여백 0(화면 가장자리 픽셀 검사).
- `tools/qa/platform_touch.mjs`·`platform_view.mjs`: fold 기기로 조이스틱·스킬 원호·탑승·빠른 칸·미니맵 누르기·퀘스트 창 접기, 회전(가로↔세로)·접기/펼치기(화면 크기 바뀜) 때 즉시 재배치.
- 성능: HUD 그리기 휴대폰 저사양 p95 예산 유지(아이콘·틀은 미리 구운 캔버스, 매 프레임 그라디언트 금지).
