## 2. 확인만 하고 남긴 것
- **얼굴·정체성**: 14직업 측면 원화를 초상화와 나란히 봄 — 세라 은발·파란 눈·베일/머리 장식, 빅터 수염·흑발·챙 모자(처형인 가면, 팬텀 두건은 classes.js headgear 그대로). 계급별 화려함도 단계대로. 문제 없음.
- **원소술사 y135 · 처형인 y135 가 약한 3/4**(15~25°): 카엘 헌터 y135 와 같은 수준이라 둠.
- **퇴마사 뒤(ym90) 크림색 vs 새 q3b**: turn5 네 뷰가 모두 크림(b−r ≈ −26), 측면 아틀라스는 중립 흰색(−8). 새 q3b 는 turn5 와 같은 크림.
- **팔뚝 중간점(fa1/fa2) 이음매 검사**(원소술사·대마법사·폭풍의 소환사 47~50셀): 확대 확인 결과는 §5.
- **퇴마사 편 손이 검지를 편 손**(축복 손짓)·건로드 편 손 OK 모양: 게임 배율에서 안 보이고 시전 손짓으로 어색하지 않아 둠.
- **바닥 그림자**가 턴 뷰 일부(y135/y180, 성녀 ym90 등)에 옅게 남음: 발 밑 접지 그림자로 읽힘. 지우는 규칙(무채색 회색)은 검은 장화 밑창까지 먹어서(시험) 넣지 않음.

## 3. 공용 도구 변경 (최소·하위 호환)
- `tools/puppet/build_turn.py`: `bg_pockets()` + `cut_views(..., pockets=None)`. 리그 `turn.pockets = {T, frac, min}` 가 있을 때만 — 첫 `fill_holes` 가 되살린 구멍 중 rembg 가 투명으로 봤고 화소의 `frac` 이상이 그 줄 배경색(좌우 24px 중앙값)과 `T` 이내인 덩어리(`min` px 이상)를 두 번째 `fill_holes` 뒤에도 비운다. `extra` 항목마다 `pockets` 로 따로 줄 수 있다.
  **흰 옷에는 켜지 말 것**: 그늘진 흰 천(≈200)이 배경 회색과 같아 퇴마사 뒷모습에서 로브 판이 통째로 지워졌다(시험). 옵션이 없으면 결과는 예전과 바이트 단위로 같은 로직(카엘·브란·리아·아젤 영향 없음).
- (1차 리뷰) 런타임(hero.js·hero_puppet.js)은 건드리지 않음. 재검수에서 `bodyTop` 때문에 후광 자리 두 줄을 고침 — §6.

## 4. 파이프라인에 넣을 교훈
1. **3/4 뒷모습 라벨은 머리 방향으로 정한다**: 귀·옆뺨·코끝이 보이는 쪽이 얼굴 방향. 클링은 "LEFT figure turned away to the viewer's left" 를 자주 반대로 그린다(빅터 7장 중 3장). 두 인물이 좌우 대칭인지 보고, 각 인물의 머리 방향으로 ym45/ym135 를 붙일 것.
2. **정면 뒷모습(좌우 대칭)은 3/4 뒤로 쓰지 말 것** — ym90 과 중복. 한 장짜리 재생성에 **뒷모습 잘라낸 것을 image_2 로** 주면(등 디자인 기준) 3장 중 3장이 비스듬한 뒷모습이 나왔다(한 직업은 두 후보 중 하나가 옆모습). 대신 거의 항상 걷는 보폭 자세로 나온다.
3. **흰 옷 + 밝은 회색 배경 = rembg 구멍** 은 측면뿐 아니라 새로 만든 턴 뷰(q3f/q3b)에도 똑같이 생긴다. 새 시트를 넣을 때마다 마젠타 배경으로 알파를 볼 것. 배경이 균일하지 않은 시트(q3f)는 줄별 배경색 대신 **지역 배경색(정규화 블러)** 으로 flood fill.
4. **`build_turn` 의 구멍 메우기는 배경 주머니도 메운다** — 어두운 옷 직업은 `turn.pockets` 를 켠다. 긴 코트 + 늘어뜨린 팔(빅터)은 거의 항상 팔-코트 사이가 갇힌 주머니가 된다.
5. **발 검사**: 측면 원화 알파의 발 주변(뒤꿈치 아래 그림자 방울, 발끝 반사광 틈)을 확대해서 보고, `footLine` 이 발끝 윗면을 지나지 않는지(선+40px 가 발끝 위) 확인. 6배 확대 skid/walk/wall 셀에서 발끝·뒤꿈치에 실오라기가 없어야 한다.

## 6. 재검수 (retry, 1차 리뷰 뒤 두 번째 적대적 검수)

1차 리뷰가 끝난 뒤 다시 14직업을 봤다. 새로 찾은 것은 **직업마다 몸 크기가 다른 문제** 하나를 고쳤고, 나머지는 확인만 했다. 클링은 쓰지 않았다(0장).

### 6.1 고친 것: 머리 장식이 배율 기준에 들어가 직업마다 몸 크기가 다름
- 원인: `build_rig` 의 `figTop` = 알파 맨 위(관·모자 포함) → 런타임 `PS = 90 / (sole − figTop)`. 높은 머리 장식 직업일수록 몸이 작게 그려졌다.
  기본 직업 대비 몸 크기(고치기 전): 성녀 −8.4% · 대마법사 −6.5% · 원소술사 −5.3% · 대사제 −3.3% · 폭풍의 소환사 −2.1% / 건로드 −4.8% · 팬텀 −1.2% · 데스페라도 −0.9% (처형인 +0.7%).
  턴테이블 뷰도 같은 기준(`measure` 의 맨 위)이라 직업 안에서는 일관됐지만, 전직하면 몸이 줄어드는 것처럼 보였다(게임·메뉴 모두).
- 조치 (opt-in, 하위 호환):
  - `tools/puppet/build_rig.py`: 리그 `bodyTop`(원화 px) 이 있으면 `figTop = bodyTop`(배율 기준), 실제 알파 맨 위는 rig.json `artTop` 에 기록.
  - `tools/puppet/build_turn.py`: `bodyTop` 리그면 측면 원화에서 머리 장식이 차지하는 몫 `(figTop − artTop)/(sole − artTop)` 을 각 뷰의 `topY` 에 똑같이 적용(`measure(img, frac)`, 뷰별 덮어쓰기 `turn.bodyFrac`). → 옆모습 퍼펫과 채색 뷰의 몸 크기가 같다.
  - `src/render/hero_puppet.js`: 후광을 `artTop` 위에(측면 `drawLayers`, 턴 `drawTurnHalo(ctx, col, t, I)`), `src/render/hero.js` 는 `drawTurnHalo` 에 `I` 를 넘기는 한 줄. `artTop` 이 없으면(카엘·브란·리아·아젤) 예전과 같은 값.
  - 값: `sera_exorcist.json bodyTop 225`(베일 맨 위), `victor_gunslinger.json bodyTop 223`(모자 맨 위) — 기본 리그에 넣어 7직업이 상속. keep-pose 편집이라 직업 원화의 발바닥 y 가 2540~2575(±0.7%)로 같아서 원화 px 상속이 맞다(확인).
- 결과: 14직업 모두 몸(정수리~발) 크기가 같고 관·모자·깃털만 위로 나온다(`size_after2/size_*.jpg`: 옆·20°·45°·정면·뒤 5방향 × 7직업).
- 주의: rig.json `v`(원화·알파·**직업 리그 파일** 해시)는 기본 리그의 변경을 반영하지 않는다 — `bodyTop` 을 기본 리그에 넣어도 파생 직업의 `v` 는 그대로. 매니페스트 해시는 산출 파일 해시라 캐시 무효화는 정상. "원화·리그 해시로 최신 여부 검사"를 할 때는 `extends` 체인 전체를 봐야 한다.

### 6.4 교훈 (PUPPET_PIPELINE.md 에 합칠 것)
1. **배율 기준은 머리 장식을 빼고 잡는다**: 관·모자·깃털이 높은 직업이 있는 영웅은 기본 리그에 `bodyTop`(장식 없는 기본 직업의 정수리 y) 을 넣는다. 파생 직업의 원화가 keep-pose 편집이면 원화 px 그대로 상속된다(발바닥 y 가 같은지 확인). 턴 뷰는 build_turn 이 같은 몫을 자동 적용.
