# heroes1 작업 노트 — 세라(sera) · 빅터(victor) 채색 퍼펫

PUPPET_PIPELINE.md 를 따라 두 영웅 × 7직업을 만들면서 배운 것. 리드가 나중에 본 문서에 합친다.
클링 기록: `tools/puppet/kling_manifest_heroes1.json` (세라 40장, 빅터 42장 — 예산 45장 이내, 재시작 후 추가 생성 0장).

## 1. 클링 원화

### 1.1 기본 측면 원화
- 초상화를 `image_1`, 카엘 측면을 `image_2`(포즈) 로 준 첫 시도(3장씩)는 전부 **초상화 구도(정면·3/4)** 였다. 세라는 애니풍 + 베일이 망토처럼 날림.
- 두 번째부터 **카엘 측면 원화를 포즈·구도 기준(`image_1`)**, 첫 시도에서 옷·얼굴이 좋은 후보를 정체성(`image_2`)으로 → 자세·구도가 카엘과 같아져
  관절 배치도 카엘과 거의 같다. 화풍 변환 요구("realistic painterly")는 무시되고 초상화 화풍(세라 애니풍)을 따른다 — 영웅 식별이 우선이라 그대로 둠.
- 세라 베일은 등 뒤로 허리까지 늘어진 모양으로 채택 → `pony` 띠(흔들림)로 쓴다(`ponyN 6`, `rest 0.45`).

### 1.2 직업 원화 (keep-pose, 직업당 2후보)
- 템플릿 그대로 12직업 × 2후보 중 채택 불가 없음. 고른 기준(매니페스트 note): 팔 둘레에 떠 있는 번개 고리·발에 붙은 불꽃·권총집에 든 권총·
  모자 뒤로 길게 뻗은 연기·가시가 많아 윤곽이 지저분한 후보는 버림.
- 빅터 처형인은 모자 대신 긴 흑발 + 입 가리개, 팬텀은 두건으로 나왔다(classes.js look.headgear 반영). 얼굴은 모두 보인다.

### 1.3 턴어라운드
- 레이아웃 참고 시트(카엘 5뷰)를 `image_2` 로 주면 **카엘의 채찍 똬리·포니테일이 빅터에 새어 들어왔다**(2장 실패).
  → 참고 이미지 없이 글로만 배치("five full-body views from left to right: front, three-quarter front, side, back, …") → 12장 모두 쓸 수 있음.
- 그래도 뷰 순서가 흔들린다: 3/4 앞이 정면 중복(팬텀), 옆모습 둘(헬파이어·데스페라도), **오른쪽을 보는 옆모습**(건로드 3번째 = y0 → 버림).
  라벨은 시트마다 눈으로 정했다(아래 표). 3/4 앞이 없으면 3/4 에 가까운 옆모습을 y135 로 쓴다 — 턴테이블의 0°/180° 는 원화 옆모습이 아니라
  게임 퍼펫이 그리므로 y180 뷰는 실제로 쓰이지 않고, 정면을 y135 로 쓰는 것보다 "왼쪽을 본다"는 방향이 맞는 편이 자연스럽다.
- 3/4 뒷모습: 세라는 한 장짜리(3:4)로 요구 → 6장 중 3장은 정면 뒤에 가까움(그래도 `ym135` 로 씀, 거울상으로 ym45). 빅터 2뷰 시트는
  왼쪽 인물이 앞모습(팬텀·건로드) 또는 둘 다 정면 뒤. **팬텀은 쓸 수 있는 3/4 뒤가 없어 정면 뒷모습을 `extra` 로 ym135 에 재사용**.
- **빠진 방향은 턴테이블에서 빈칸이 된다**(`drawTurnStep` 이 null) — 8방향이 모두 채워졌는지 `build_turn` 의 "! 방향 없음" 경고를 꼭 볼 것.
  (단 0°/180° 는 옆모습 퍼펫이 그리므로 y0/y180 이 없어도 빈칸이 아니다 — 데드아이의 "[0, 180] 없음" 경고는 무해.)
- **3/4 앞(y135)이 정면 중복인 시트**(퇴마사·폭풍의 소환사·건슬링어, 팬텀은 옆모습으로 대신) → 턴테이블 45°~135° 가 거의 같은 정면으로 보였다.
  재시작 후 **한 장짜리 3/4 앞**을 따로 생성(`<cls>_q3f`, 3:4, `image_1` = 직업 측면 원화, `image_2` = turn5 의 정면 뷰 잘라낸 것(옷 앞면 디자인)) →
  `turn.extra: [{"sheet": "<char>/<cls>_q3f", "views": ["y135"]}]`, turn5 의 해당 라벨은 `-`. "turned about 45 degrees toward the viewer's LEFT …
  nose and toes point toward the left edge" 로 세라는 2/2 성공, 빅터(건슬링어)는 2장 모두 **옆모습에 가깝게 과회전**(≈70°) → 팬텀은 "only about 35 degrees,
  closer to a front view … both arms and both legs visible" 로 요구해 약한 3/4 가 나왔다. 여자 애니풍은 45°, 남자 사실풍은 30~35° 로 요구하는 편이 맞다.

### 1.4 손 시트
- 막대 방향이 제각각(세로·가로·대각선, 막대가 손가락 앞을 지남). 흰 장갑 시트는 rembg 가 편 손 손바닥을 통째로 배경으로 지웠다(§2).
- 광택 검은 장갑(데드아이)은 막대의 초록이 장갑에 반사되고, 막대 위 **흰 하이라이트 줄**은 키잉되지 않아 주먹 가운데에 흰 줄이 남는다
  (메뉴 배율에서만 보임). 반사가 적은 무광 장갑 묘사("matte leather glove")를 요구하는 편이 낫다.

## 2. 알파(rembg) — 흰 옷·흰 장갑이 밝은 회색 배경에서 지워진다
- 대사제(흰 비단 로브)의 뒤 자락·안감, 흰 장갑 편 손이 rembg 에서 배경으로 빠졌다 → `skirt` 부품이 금테만 남고 텅 빔.
  성녀는 반대로 **바닥 그림자까지 인물로** 잡혔다.
- 보정 방법(작업 폴더 스크립트 `fix_alpha.py`, 결과 `_alpha.png` 만 커밋):
  1. 행별 배경색(좌우 30px 중앙값)과의 거리 < 12 인 화소 중 **테두리에서 이어진 것만 배경**(flood fill). 애니풍 윤곽선이 있어 흰 옷 안쪽은 막힌다.
  2. 바닥선(발목 위, y≈2200) 아래의 무채색 회색(채도 < 0.12, 밝기 80~228)도 배경으로 이어지게 → 그림자가 떨어지고 **장화 사이 배경 주머니**도 빠진다.
     (그림자 윗변에 밝기 213~223 의 흰 테두리 줄이 있어 밝기 상한을 205 로 두면 주머니가 막힌다.)
  3. 새 알파 = rembg ∪ (배경이 아닌 곳) − (바닥선 아래 배경과 이어진 어두운 곳), 구멍 메움. 발광 밑단의 번짐 띠는 `open 81` 로 버림.
  - 검사: 알파 밖을 마젠타로 칠한 원화를 반드시 본다(구멍·그림자·주머니).
- 턴어라운드 시트의 rembg 는 흰 옷에서도 괜찮았다(인물이 작고 윤곽선이 굵음).

## 3. 리그 테이블
### 3.1 세라 (두 조각 자락)
- 기본(퇴마사): 앞이 트인 로브 = 카엘 코트와 같은 두 조각 자락 — `skirt` = 가까운 쪽 뒤 자락 판, `skirtFar` = 가까운 다리 뒤로 보이는 먼 쪽 앞 자락 판.
  런타임 변경 없이 된다(`drawSkirtFar` 가 이미 있음). 다리는 밑단 아래만 보이므로 `leg` 는 카엘과 같은 모양이면 충분.
- **바지 색 분리(`pantsWarmMax`)는 옷 색마다 다르다**: 퇴마사(남색 타이츠)는 −0.02 로 되지만 대사제·성녀(흰 타이츠)·대마법사(검은 타이츠)는
  넓적다리가 인페인트 회색 얼룩, 정강이 윗부분이 통째로 빠짐 → `legs.pantsWarmMax: null`(영역으로만 자름). 빅터 데스페라도(올리브 바지 + 녹슨 갈색 코트)도 같음.
- 챙 넓은 모자(원소술사·대마법사): 기본 리그의 베일용 `pony` 영역이 **챙 뒤쪽 조각**을 물고 흔들렸다 → `head` 아래선을 챙 밑선 바로 아래로,
  `pony` 는 챙 밑에서 시작해 팔 밖으로 보이는 은발만. 팔·어깨 덮개와 겹치는 머리카락은 몸통 부품에 남는다(정적).
- 베일 직업(대사제·성녀·신탁)은 기본 리그 그대로(머리 장식이 높은 직업만 `head` 위를 캔버스 위끝까지).

### 3.2 빅터 (긴 코트·쌍권총)
- 카엘과 같은 긴 코트 → `skirt` 한 장 + 다리 사이 안감 없음(`skirtFar: null`). 모자 → `head` 를 챙 끝까지, `pony: null`, 권총집은 몸통에 남김(`coil` 없음).
- **팔과 코트 사이 배경 틈**: 가까운 팔이 몸 옆에 늘어진 원화라 팔-코트 사이에 배경이 보이는데, 몸통 실루엣(`fig_body`)은 갇힌 구멍을 메우므로
  `torso` 영역이 틈까지 넓으면 배경 회색이 몸통 부품에 그대로 남는다(팬텀: 팔을 들면 허리에 밝은 회색 띠). → `torso` 왼쪽 선을 틈의 코트 가장자리에 붙인다
  (알파에서 행마다 팔-몸 사이 배경 구간을 찾아 좌표를 얻음). `uarm` 이 덮는 곳은 인페인트되므로 문제없고, 팔꿈치 아래(y 1080~1250)만 조심.
- 가시 견갑(처형인): 기본 `pad`/`torso` 위선이 가시를 잘랐다 → 둘 다 가시 끝까지 넓힘(`pad` 는 `torso` 안에서만 잘리므로 둘 다 넓혀야 한다).
- 쌍권총: 런타임이 이미 지원(`K.off` → 먼 손도 `grip`, 어둡게). 추가 작업 없음.

## 4. 런타임 변경 (hero.js, 최소·하위 호환)
- **총 반동을 퍼펫에서만 0.03초 늦춤** (`gunPose`: `kd = K.pup ? 0.03 : 0`).
  측정(작업 폴더 `muzzle.mjs`: 발사 프레임 moveT = hit[0]+0.005 에서 총구 = 손 + 무기 방향 × weaponReach, T1→월드):
  예전에는 발사 순간 이미 반동(팔 +0.42, 손목 +0.85 rad)이 최대라 총구 섬광이 탄 생성점(offX 44, offY −60)보다 **≈47px 위**(머리 높이)에 찍혔다(벡터도 42px).
  지연 후 퍼펫 총구 = (44.3, −78.9) → 가로는 정확히 일치, 세로 −19px(어깨 높이). 벡터는 그대로(비교용).
- **퍼펫 총 조준 풀이 `aimPup`** (재시작 후 추가, `gunPose` 에서 `K.pup` 일 때만): 위의 남은 세로 차이를 탄 데이터가 아니라 **자세**로 없앴다.
  조준 끝 자세(PE)에서 원화 어깨(`K.pS1/pS2`, lean·py 반영)를 구하고, 손 목표 = 탄 생성점(movesets `proj.offX/offY` ÷ 게임 배율 `drawScale × look.height`)
  − 총구 오프셋(무기 좌표 `(1.3·(MUZZLE+1), −2.6)` 를 조준각 w 로 회전) → `a = atan2`, `r = 거리/(ua+fa)` (0.5~1, 팔꿈치는 IK 로 굽음).
  대상 anim: shoot · shoot_alt(먼 손) · shoot_double(양손, 먼 총은 (−1.5, −3) 비켜 겹치지 않게) · shoot_up · crouch_shoot · slide_shoot. shoot_down 은 원래 4~6px 이내라 제외.
  메뉴(`opts.scale`)에서도 게임 배율로 풀어 자세가 같다. 결과(`muzzle.mjs`, 건슬링어 ±facing): 모든 수평·위 사격 **d = (0, 0)**, 양손 먼 총 (−1.7, −3.5),
  crouch (−1.1, −1.5), slide (−2.4, −1.2), down (−5.8, −3.5, 변경 없음). 이전 퍼펫 (6, −19)·벡터 (19, −14). 7직업 모두 같은 값(원화 포즈가 같음).
  모양: 가슴 높이에서 팔꿈치를 굽혀 쏘는 총잡이 자세 — 수평으로 편 팔보다 자연스럽다. 탄 데이터(movesets/skills/player.js)는 건드리지 않음.
- **퍼펫 + 지팡이 투척(`poseThrow`)**: 대기 자세의 지팡이 기울기(holdFor 퍼펫 보정 w1 −1.27) 그대로 손만 엉덩이 옆으로 내려가 **지팡이 머리가 얼굴을 덮었다**
  (세라 성수 투척 = 자주 보이는 동작, 벡터도 같은 문제). 퍼펫일 때만 `w1 = lerp(−0.95, −0.7, k)` 로 앞으로 비스듬히 → 얼굴이 보임.

## 4b. 워터마크 (재시작 후)
- `ingest.py`/`remove_watermark` 의 상자(세로 95.2%~)는 9:16 측면 원화 기준이라 **16:9 손 시트·21:9 턴 시트·4:3 3/4 뒤 시트에서는 글자가 상자 위로 걸쳐 남았다**
  (카엘 원본 시트도 같음). 글자는 불투명 흰색(α≈1)이라 역합성으로는 못 살리고, 이미지 크기별 위치가 고정이다.
  → 작업 폴더 `wm_fix2.py`: 같은 크기의 모든 원화(전 영웅, 읽기만)에서 "흰 글자" 화소가 40% 이상인 곳 = 템플릿(2px 팽창) → 그 자리만 inpaint.
  2720×1536: x 2278–2661, y 1436–1463 · 3104×1312: x 2726–3054, y 1227–1250 · 2336×1760: x 1841–2282, y 1655–1676 (1760×2336 세로 시트는 ingest 가 이미 지움).
  굵게 남은 2장(sera_exorcist_qback, victor_gunslinger_qback)은 같은 상자에서 밝은 무채색만 한 번 더. 장화·그림자에 걸친 글자는 흐린 얼룩으로 메워짐(턴 배율에서 안 보임).
  손 시트의 글자는 원래 손 상자 밖이라 아틀라스에는 없었지만, 턴 시트 5번째 뷰(건로드 ym90)·3/4 뒤 시트는 인물 발 옆이라 turn.webp 에 들어갈 수 있었다.
