리뷰는 두 번에 나눠 했다(첫 실행: §1 의 1~5, 둘째 실행(컨텍스트 재시작 후): 6~8 과 §5 재검증 전부, 새 클링 생성 0).

## 2. 확인만 하고 남긴 것
- **정체성·직업 묘사**: 7직업 측면 원화를 초상화·classes.js look 과 나란히 봄. 은발·붉은 눈·같은 얼굴, 단계별 화려함(담피르 검은 코트 → 진조 붉은 안감 → 노스페라투 박쥐 날개 · 혈왕 금관·붉은 망토 / 성검사 흰 판금·보라 → 여명 금빛 → 타천사 흑백 날개·후광). 무기는 전 직업 장검(characters.js `weaponTypes ['sword']`). 드리프트 없음.
- **달리기 방향 전환 때 뒤로 날리는 흰 덩어리**: 테스트 도구 착시. 30틱마다 한 번 그리면 사슬(머리카락·망토) 물리가 dt 클램프(0.05)와 관성 전달로 늘어나 덩어리처럼 보인다. 매 틱 그리면 마디 간격 ~5px 로 정상. 카엘도 같은 조건에서 똑같이 보임.
- **NPC review.html 이음새 표시**(el2·fa2·kn1·sn1 등): 먼 팔이 몸에 가려지거나 무릎이 치마 속이라 관절 주변 알파가 원래 낮은 곳 — 오탐. 눈으로 73칸 모두 확인.
- **알베르토 걷기에서 다리가 거의 안 보임**: 수단이 발목까지 내려오는 원화 그대로.

## 4. 파이프라인에 넣을 교훈
1. **3/4 뒷모습은 생성 직후 "좌우 대칭인가"를 먼저 본다** — qback 시트 두 인물이 모두 정면 뒷모습이면 −45/−90/−135 가 같은 그림이 된다. 한 장짜리 `q3b`("왼쪽으로 돌아서 옆뺨과 코끝만 보이는 3/4 뒷모습")가 시트보다 성공률이 높았다(첫 시도 7장 중 5장 채택, 실패 2장은 흰 판금 성검사·여명 → 재시도 2장씩에서 채택. 흰 판금 직업이 실패하기 쉬움).
2. **`bodyTop` 은 기본 리그에 처음부터** (heroes2rev 와 같은 교훈이 또 나옴 — 왕관 하나로 4.9%).
3. **정강이 띠(footLine+40)는 발끝 윗선을 물기 쉽다** — footLine 기울기를 음수로 하는 것(heroes2rev)으로 안 되는 원화(구두 앞코가 높은 NPC)는 `legs.shinToeCut` 으로 발끝 방향 거리를 자른다. 대기 자세에서도 정강이가 원화보다 세워지는 리그라면 거의 항상 필요.
4. **긴 치마 인물은 넓적다리 부품을 만들지 않는다** — 안 보이는 부품이 인페인트 사각형으로 남아 걷기에서 튀어나온다.
5. **치마·코트 인페인트 표본은 옷 밝기로 제한하고, 팔 둘레를 넉넉히 판다** — 표본에 손 그늘·피부가 섞이면 팔이 비킬 때 얼룩이 된다. 몸통 영역 경계는 소매 밑에서 수직선으로 두지 말고 실제 등 윤곽을 따라 안쪽으로.
6. **NPC 결함은 실제 데이터로 본다** — review.html 은 NPC 에 `equip.weapon = null` 을 주면 죽는다. `gallery_hero.html?sec=npcpup` 과 허브·스토리 스테이지에서 NPC 옆에 플레이어를 세워 확대 캡처하는 쪽이 확실했다.

### 5.1 QA 도구에서 배운 것
- **review.html 의 `yaw` 는 라디안** (갤러리 `cell.turn` 은 도). 도 단위를 넘기면 16각이 뒤섞여 "방향이 뒤죽박죽"으로 보인다 — 첫 턴테이블 몽타주가 그랬다.
- **서비스 워커가 `page.route` 를 우회한다** — sw.js 가 들어온 뒤로는 localhost 에서 등록되어, 처음 두 요청 뒤의 퍼펫 요청이 가로채지지 않았다(차단 모드인데 퍼펫이 로드됨). 로드 대체 시험은 `browser.newContext({ serviceWorkers: 'block' })` 또는 `?nosw`.
- **사슬 물리는 매 틱 그려야 한다** — 여러 틱을 몰아 돌리고 한 번 그리면 dt 클램프 때문에 머리카락·망토가 늘어난 덩어리로 보인다(§2).
- review.mjs 의 `Failed to load resource 404` 한 줄은 favicon.

### 5.2 남긴 것 (범위 밖 — 리드 판단)
- **방향 전환 때 망토가 수평·위로 휙 넘어감** (3~4프레임, 약 0.1초): 아젤뿐 아니라 카엘 성전 기사 등 망토가 있는 모든 영웅이 같다 → `hero.js` 의 공용 망토 사슬(`chain('cape', …)`) 문제. 이 리뷰의 범위(`hero.js` 수정 금지) 밖.
- 자동 저장 프로세스(다른 주체)가 작업 트리를 주기적으로 커밋한다. 이 리뷰는 커밋하지 않았다.
