# heroes2 리뷰 노트 — 브란(bran) · 리아(lia) 채색 퍼펫 검수 (heroes2rev)

생산 보고(notes_heroes2.md)를 믿지 않고 14직업을 다시 본 결과와 고친 것. 리드가 PUPPET_PIPELINE.md 에 합칠 교훈은 §4.
클링 기록: `tools/puppet/kling_manifest_heroes2rev.json` (리뷰에서 새로 만든 원화만: 브란 1장(실패), 리아 3장 → 생산 포함 브란 41장, 리아 48장).
리뷰는 두 번에 나눠 했다(첫 실행은 사용량 한도로 중단 — §1 의 1~5 가 첫 실행, 6~11 이 재개 후).

## 2. 확인만 하고 남긴 것
- **정체성·직업 묘사**: 14직업 측면 원화를 초상화와 나란히 봄. 브란 붉은 수염·옆머리 민 머리·같은 얼굴, 리아 검은 단발·가면·붉은 눈(그림자 군주 보라, 사신 초록 — classes.js `eyes` 그대로). 단계별 화려함(기사→성기사·광전사→왕관·월계관·뿔 왕관·악마 뿔)과 look 색(성기사 흰 판금+청색, 십자군 크림+진홍, 전쟁군주 검은 판금+금, 카게로우 적갈+분홍, 사신 검정+초록) 모두 맞음.
- **수호성기사 3/4 뒤(대칭 뒷모습)**: 한 번 재생성했으나 실패. 턴테이블에서 −45/−90/−135 는 절차적 청색 망토(1.2)와 등의 대검이 몸통을 거의 다 덮어 머리·어깨만 보인다(`turn_bran_gal.jpg`) → 추가 생성 안 함.
- **약한 3/4 앞(y135)**: 암살자·닌자·무희·카게로우는 거의 정면(15–20°). 카엘 헌터와 같은 수준이라 둠.
- **암살자 3/4 뒤에만 그려진 긴 붉은 스카프 꼬리**: −45°/−135° 에만 보이고 −90° 에는 없음. 턴테이블은 스카프 꼬리를 절차적으로 그리지 않는다. 작은 불일치라 둠.
- **카게로우 옆 뷰(y180)의 포니테일**: 턴테이블 0°/180° 는 옆모습 퍼펫을 쓰므로 이 뷰는 화면에 나오지 않는다.
- **기사의 편 손(검은 가죽 장갑) vs 주먹(강철 건틀릿)**: 시전·투척 때만 잠깐. 둠.
- **턴 뷰 발밑 옅은 회색 그림자**(성기사·수호성기사 앞): 접지 그림자로 읽힘(heroes1rev 와 같은 판단).
- **대검 회전 베기(heavy_spin)·대시에서 한두 프레임 얇은 판**: 파이프라인의 알려진 한계(§10).

## 3. 공용 도구·런타임 변경
없음. 리그 테이블·원화 알파(`tools/puppet/{rigs,src}/{bran,lia}/`)만 고쳤고, 쓴 옵션(`bodyTop`, `turn.pockets`, `hands.rodKey`)은 heroes1rev·첫 실행에서 이미 들어간 것이다. `hero.js`·`hero_puppet.js`·`build_*.py` 는 건드리지 않음.
빌드: `build_all.py bran -j 3`, `build_all.py lia -j 3`, 알파만 고친 성기사·십자군은 `build_turn` 만 다시 + `write_manifest()`.

## 4. 파이프라인에 넣을 교훈
1. **`bodyTop` 은 영웅의 기본 리그에 처음부터 넣는다** — 뿔·왕관·두건이 있는 직업이 하나라도 있으면 없을 때 그 직업만 작아진다. 확인: 모든 직업 rig.json 의 `sole − figTop` 이 같아야 한다(한 줄 스크립트).
2. **pockets 를 켜기 전에 지워질 덩어리를 눈으로 본다** — 흰 판금은 rembg 가 판 속을 뚫어 두는 일이 잦고(수호성기사), 그 구멍은 `fill_holes` 가 가려 주다가 pockets 를 켜는 순간 드러난다. 판 속 덩어리는 `_alpha.png` 에서 먼저 메운다.
3. **rembg 실패는 세 가지 모양이 있다**: (a) 안쪽 구멍 — `fill_holes` 가 메움(흰 옷이면 pockets 주의), (b) 윤곽 밖으로 이어진 결손 — 성기사 견갑처럼 아무 규칙도 못 메움, 알파를 손으로, (c) 배경을 인물로 남김 — 십자군 팔 옆, pockets 로도 안 잡힘. 턴 뷰를 **마젠타 배경 + 청록(지울 곳)** 으로 한 장씩 보는 것이 가장 빠르다.
4. **손 시트 막대 키는 넉넉하게 기본 직업에** — 기본 키는 그늘진 막대를 놓친다. `rodKey {hue:[60,185], sat:0.1, val:0.08}` 는 14직업 모두에서 주먹·장갑을 해치지 않았다(검은 장갑·맨손 포함).
5. **footLine 은 기울기를 음수로** — 발끝이 들린 옆모습 원화에서는 +기울기면 거의 항상 발끝 윗면이 정강이로 간다.
