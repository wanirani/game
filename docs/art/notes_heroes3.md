## 1. 클링 원화

### 1.1 아젤 측면 (앞선 실행)
- 기본 측면(담피르)은 **카엘 헌터 측면 원화를 편집 대상(`image_1`)** + 초상화(`image_2`, 정체성)로 → 자세·구도가 카엘과 같아 관절 배치가 거의 같다(heroes2 §1.1 과 같은 결론).
- 직업 6장은 담피르 원화에서 keep-pose 편집, 직업당 2후보. 버린 후보: 날개를 그린 노스페라투('no wings' 무시), 모피 망토를 두른 혈왕, 자락 전체가 보라인 성검사,
  뾰족한 왕관(서클릿 요구 무시)의 여명, 깃털 견갑이 날개처럼 커 팔 윤곽을 가린 타천사.
- 등급 화려함: 0단계 검은 가죽 코트 → 1단계 레이스 자보·금 필리그리(진조)/은 판금 견갑(성검사) → 2단계 박쥐 날개 견갑·발톱 건틀릿(노스페라투),
  금관·루비 견갑(혈왕), 태양 견갑·서클릿(여명), 깃털 견갑·보라 룬 자락(타천사). 은발·붉은/금색 눈으로 7직업 모두 같은 영웅으로 읽힌다.

### 1.2 턴어라운드 — 레이아웃 참고 이미지 없이 글로만

### 1.3 손 시트
- 검은 장갑 6직업은 담피르 손 시트 공용(주먹은 게임 배율에서 ≈10px, 소매·팔찌는 wrist 선에서 잘리므로 차이가 안 보임). **발톱 건틀릿(노스페라투)만 따로** 1장.
- 성검사 흰 장갑 시트는 **어두운 배경**으로 받았다(흰 장갑이 밝은 배경에서 rembg 로 지워지는 heroes1 §2 문제 회피). 대신 초록 막대가 **주먹 밖**에 따로 그려졌다
  → 막대 키잉 없이(`rodHalf: 0`) 주먹 가운데를 `center`, 손가락 줄 방향을 `axis` 로 적어 그대로 쓴다(손잡이는 주먹 뒤로 지나가게 보임).
- 노스페라투 시트의 막대는 대각선(손가락 뒤) — `axis [0.941,0.337]`, 편 손은 발톱을 편 손(시전 손으로 충분).

### 1.4 NPC 측면
- 초상화를 `image_2`(정체성), **카엘 측면을 `image_1`(자세·구도)** 로 → 8명 중 5명은 옆모습에 가까운 3/4 로 걷는 그림. 로크·카밀라는 두 후보 모두 **정면**으로 걸어 나와
  (초상화의 정면성이 이김) 재생성: 로크는 같은 인물의 맨얼굴 측면(rook2 채택본)을 `image_1` 로 두건·가면만 바꾸는 편집, 카밀라는 **아젤 측면(엄격한 옆모습)**을 `image_1` 로 +
  "STRICT SIDE PROFILE … NOT her front" → 성공.
- "nothing held in the hands" 는 하드윈에서 무시됨(망치를 먼 손에 쥠) — NPC 는 먼 팔을 원화 그대로 두므로(§3.1) **망치가 그대로 남아 오히려 좋다**.
- 3/4 NPC 원화는 먼 팔·먼 다리가 몸 앞에 보인다. 영웅처럼 먼 팔을 버리고 가까운 팔 사본으로 그리면 어색해서, NPC 는 먼 팔을 원화 그대로 쓰는 방식으로 풀었다(§3.1).

## 2. 워터마크 — 21:9·4:3·16:9 시트는 ingest 가 반만 지운다
- `ingest.py` 의 워터마크 상자(세로 95.2%~)는 9:16 기준이라 5뷰(3104×1312)·3/4 뒤(2336×1760)·손(2720×1536) 시트에서 **글자 윗부분이 남았다**(아젤 16장 모두).
  heroes1 §4b 와 같은 방법으로 해결: 같은 크기의 저장소 원화 전부(읽기만)에서 "배경보다 밝은 무채색 글자" 화소가 40% 이상인 곳 = 템플릿(2px 팽창) → 그 자리만 inpaint.
  상자: 3104×1312 x 2690–3090 y 1200–1262 · 2336×1760 x 1800–2320 y 1630–1690 · 2720×1536 x 2240–2700 y 1410–1475. 장화에 걸친 글자는 흐린 얼룩으로 메워짐(턴 배율에서 안 보임).
- `build_turn.cut_views` 는 워터마크 자리(가로 80%~, 세로 93%~)의 알파를 지우므로 5번째 뷰의 발끝이 잘린다 — 5번째 뷰는 대개 `-`(버림)라 문제없음.

## 3. 리그 테이블

### 3.1 아젤 (`rigs/azel/`)
- 담피르가 기본, 6직업은 `extends` + `src/hands/turn/materials/runtime.armorBase` 와 **튀어나온 견갑만** `torso`/`pad` 덮어쓰기:
  노스페라투 박쥐 날개 견갑(왼쪽 x 418 까지), 혈왕 금관(`head` 를 y 70·x 1200 까지)·루비 견갑, 성검사 큰 은 견갑 + 먼 쪽 견갑(몸통 오른쪽 윤곽 x 1092 까지),
  여명 태양 견갑의 긴 가시(왼쪽 x 380·위 y 505, 오른쪽 x 1105), 타천사 깃털 견갑. 견갑을 몸통으로 넓히면 그 자리의 포니테일 영역은 자동으로 빠진다(`pony_m = … & ~torso`).
- 긴 은발(`pony`, `ponyTopY 3000` = 밝은 머리카락도 전부)은 영역 다각형만으로 잘린다 — `hairLum` 은 "어두운 머리카락" 기준이라 은발에는 못 쓴다.
  포니테일 영역이 가까운 위팔 뒤쪽 윤곽에 닿으면 **팔 윤곽 조각이 머리카락 끝에 매달린다**(노스페라투에서 발견) → 영역 아래쪽 경계를 팔에서 20–30px 떼었다.
- 재질: 검은 가죽 `sat<0.42 & val<0.5`(담피르·진조·노스페라투, 붉은 조끼·레이스는 채도·밝기로 빠짐), 혈왕 진홍 `hue 335~25, sat>0.3`, 성검사 흰 코트·은 판금 `sat<0.2, val>0.42`
  (보라 소매·팔은 제외), 여명 상아 판금 `hue 15~70, sat<0.4, val>0.45` + 금 트림 `sat>0.45`, 타천사 남색 `hue 195~255` + 아주 어두운 곳, 트림 보라+금.
- **엉덩이 이음매 두 곳**(담피르에서 발견, 7직업 공통으로 상속): ① 가까운 아래팔 오른쪽과 코트 자락 사이(x 585–610, y 1150–1290)에 1px 배경 줄 → `skirt` 왼쪽 위를 x 555 까지,
  ② 넓적다리의 바지 주름선(coatEdge 띠)이 넓적다리 모양 밖이라 빈 줄 → `legs.thighWidth` 108→130. `reassembled.jpg` 를 마젠타 배경으로 확대해야 보인다(작업 폴더 `reasm.py`).
- 팔 밑 몸통 인페인트가 **회색**으로 떴다(검은 광택 가죽의 중간 톤이 회색) → 팔을 앞으로 흔들면 코트 뒤에 회색 조각. `torsoTone 0.45→0.15`, `torsoSrcMaxLum 110→60`.
  흰 옷 직업(성검사·여명)은 `torsoSrcMaxLum: null`, `torsoTone 0.4` 로 덮어씀.

### 3.2 NPC (`rigs/npc/<npcId>.json`, `charId: "npc"`, `classId` = NPC id)
- NPC 원화도 카엘 측면을 편집 대상으로 만들었으므로 **다리 관절(엉덩이·무릎·발목·발끝·발바닥)이 카엘과 거의 같다** → 카엘 헌터 리그를 겹쳐 보고 시작하면 빠르다.
- **먼 팔은 원화 그대로 몸통 부품에**(`farArm: null`, `runtime.farArm: false`): 3/4 원화의 먼 팔(마르타의 손, 하드윈의 망치 든 손, 그레타·알베르토·로크의 장갑 손)이
  몸 앞에 크게 보여서, 영웅처럼 가까운 팔의 어두운 사본으로 바꾸면 어색했다. NPC 동작(대기·걷기·말하기·손짓)은 가까운 팔만 움직여도 충분하다.
  먼 팔이 치마·앞치마 가장자리와 겹치는 곳은 **치마 영역에서 빼고 몸통 영역에 넣는다**(치마 부품에 손이 남으면 치마가 돌 때 손이 둘로 보인다).
- **드레스·수단·앞치마 = `skirt` 한 장**(허리 피벗 → 밑단), `skirtFar: null`, **`skirtLegCut: null`**. `skirtLegCut` 은 "다리가 코트 앞에 있는 곳"이라
  드레스에서 다리 기둥 전체를 적으면 그 자리 치마가 인페인트되어 **회색 직사각형**이 생긴다(마르타·엘리제에서 발견).
  쉬는 자세에서 치마가 수직으로 늘어지게 `runtime.skirtRest: 0.1`(런타임 기본 회전 0.1 을 상쇄). 다리는 밑단 아래 장화·구두만 보인다.
- 어깨 덮개(`uarmCapTop`)는 영웅에서는 `pad`·몸통 밑에 숨지만 **NPC(견갑 없음)에서는 윤곽 밖으로 튀어나와 회색 혹**이 됐다(알베르토·엘리제·그레타·마르타)
  → 어깨 관절 둘레의 작은 타원(rx 55–75, ry 40–55)으로 바꿔 윤곽 안에 둔다.
- 머리 부품은 몸통 **뒤**에 그려진다 → 가슴 위로 늘어진 땋은 수염(하드윈)·땋은 머리(그레타)·스카프는 몸통 부품에 남긴다(머리에 넣으면 몸통에 가려진다).
  어깨 위 고양이(마르타)·등 뒤 털 숄(그레타, 바닥 가까이까지)도 몸통.
- 긴 머리: 엘리제의 가까운 쪽 땋은 머리+리본 = `pony`(`ponyTopY 3000`, `ponyN 5`, `rest 0.12`, `push 120` — 늘어져 조금만 흔들림),
  카밀라의 뒤로 흩날리는 흑발 = `pony`(`ponyTopY 0` → 어두운 머리카락만, 흰 팔은 자동으로 빠짐, `ponyN 7`, `rest 0.5`).
- 카밀라는 데이터(`NPCS` 의 카밀라 `look.cape`)에 절차적 망토가 있는데 원화의 붉은 안감 자락과 겹친다 → `runtime.cape: false`(원화 우선, 데이터는 그대로).
  NPC 리그는 모두 `cape: false` 가 기본값(생성 스크립트 `rt()`), 망토 데이터가 있는 NPC 는 카밀라뿐이라 실제로 달라지는 것은 카밀라 하나.
- 재질 규칙 없음(`materials: {}` → 마스크는 0, 장비 변형 없음). 손 시트 없음 → 손짓(편 손) 때는 원화의 손 부품으로 대체(`openPup` 실패 시 기존 대체 경로).
- **손 둘레의 “검은 벙어리장갑”**(QA 에서 발견, 8명 모두): `hand`·`farm` 부품은 `farm` 다각형 ∩ 실루엣이라, 다각형이 손 뒤의 치마·수단·코트까지
  잡으면 손을 움직일 때 **손 둘레에 옷 조각이 붙어 다닌다**(영웅은 손 시트 주먹이 덮어 안 보였다). NPC 는 가까운 손이 대기·걷기·말하기·손짓 내내 움직여서 바로 보인다.
  → 생성 스크립트가 거친 `farm` 다각형 안에서 **GrabCut**(확실한 전경 = 팔꿈치→손목 띠 14px + 손목→손 띠 16px, 가능한 전경 = 다각형 ∩ 실루엣)으로 팔·손만 남기고,
  2px 넓혀 윤곽을 새 `farm` 다각형(`smooth 0`)으로 쓴다. 맨손·흰 장갑·검은 장갑(검은 코트 위)까지 8명 모두 깨끗하게 분리됐다(작업 폴더 `tightarm.py`).
  몸통·치마의 인페인트 구멍도 팔 모양만큼으로 줄어 옷 원화가 더 많이 남는다.
- **팔과 몸 사이로 비치는 배경 구멍**: `build_rig` 는 몸통 부품을 실루엣 안쪽 구멍을 모두 메운 `fig_body` 로 자르므로, 원화에서 팔·몸 사이(로크·로크2·하드윈·알베르토)나
  머리카락 사이(엘리제·카밀라)로 보이는 **회색 배경이 몸통 부품에 회색 조각으로 남는다**(로크: 팔 뒤 세로 띠 30,000px). 파이프라인은 그대로 두고 리그에서 푼다:
  ① 배경색 구멍(행별 배경과 거리 < 20, 300px 이상)이 몸통 영역 경계에 닿으면 **몸통 다각형에서 파낸다**(윤곽을 다시 따서 `smooth 0` 다각형, 머리·포니테일 영역 제외 후 계산),
  ② 영역 안쪽에 갇힌 구멍은 `farArmHole`(몸통에서 빼고 인페인트) 다각형으로 → 회색 대신 주변 몸통 색. 여러 덩어리는 폭 0 다리로 이어 한 다각형에 담는다.
  엘리제의 목 뒤 구멍은 가까운 땋은 머리(`pony`) 영역을 구멍까지 넓혀 경계에 닿게 한 뒤 파냈다.
- **카밀라 위팔**: 원화는 팔이 어깨(y 610)부터 흰 피부로 내려오는데 `uarm` 다각형이 y 760 부터라 팔 윗부분이 흑발(`pony`, 어두운 화소만) 영역에 들어가 **사라졌고**,
  오른쪽은 가슴·머리카락까지 잡았다 → 어깨 관절을 (712, 690) 으로, `uarm` 을 흰 팔 윤곽에 맞추고, 포니테일 오른쪽 경계를 팔 왼쪽 윤곽에 붙이고, 몸통 영역을 팔 뒤까지 넓혀
  (팔이 움직이면 드러나는 자리) `torsoSrcMaxLum 90` 으로 어둡게 인페인트.
- 확인 도구(작업 폴더): `cov.py` = 부품 알파 합(쉬는 자세) vs 원화 알파 → 덮이지 않은 조각 목록·그림(먼 다리는 런타임 사본이라 늘 뜸), `regview.py` = 원화 위에 50px 격자·영역 다각형.
  이것으로 알베르토 목 뒤·어깨 뒤 쐐기, 그레타 숄/치마 사이 10px 세로 줄, 마르타 앞치마 옆 홈, 하드윈 장화 목 왼쪽, 카밀라 치마 왼쪽 레이스, 로크 털 소매 바깥쪽을 잡았다.

## 4. 런타임 (NPC 지원)

- **NPC 키**(앞선 실행): `puppetFor(p, look)` 가 `p.npc` 면 `npcPuppet` → NPC id = `p.npcId` → `look.npcId` → `look` 객체가 `NPCS`/`TOWN_NPCS` 의 어느 항목 것인지(객체 동일성).
  마을 `hub.js` 와 스테이지 `world.drawNPC` 는 데이터의 `look` 객체를 그대로 넘기므로 NPC 쪽 코드를 고칠 필요가 없다. 매니페스트 `npc` 묶음에 없는 NPC·결투 상대 등은 벡터 그대로.
  NPC 묶음은 형제 미리 받기 없음(스테이지에 NPC 한 명만 있어도 8명을 받게 되므로).
- **NPC 동작**(앞선 실행, hero.js NPC 가지): `talk`(가까운 손을 가슴 앞에서 박자, 고개 끄덕임) · `gesture`(가까운 손을 앞으로 들어 흔듦 → 편 손) anim 과,
  대기 중 자동 생기 `npcLife`: 대사 창의 현재 화자(`game.top.cur.who`)가 이 NPC 면 말하기, 플레이어가 다가오면 인사 손짓, 그 밖엔 NPC 마다 다른 주기(9–13초)로 가끔 손짓.
- **이번 변경**(`hero_puppet.js drawLayers`, 둘 다 리그 `runtime` 옵션, 없으면 예전과 같음):
  - `farArm === false` → 절차적 먼 팔(+보조 무기·먼 주먹·편 손)을 그리지 않는다.
  - `cape === false` → 절차적 망토를 그리지 않는다.
- 그레타는 이 작업 도중 다른 작업(CMP-TOWN)이 `NPCS.npc_greta`·`TOWN_NPCS.npc_greta`(마구간) 를 넣어 코드 변경 없이 바로 퍼펫으로 그려진다.
  로크2(레이븐 맨얼굴)는 아직 데이터에 없다 — `look` 객체를 데이터에 넣거나 `look.npcId: 'npc_rook2'` 를 주면 퍼펫으로 그려진다. 갤러리 `?sec=npcpup` 는 `look.npcId` 로 보여 준다.

## 5. 재개 실행 (앞선 실행이 도중에 끊긴 뒤 이어서) — 고친 것과 QA

### 5.1 인벤토리 (디스크에 있던 것)
- 클링 원화는 **전부 있었다** — 아젤 32장 · NPC 20장(`kling_manifest_heroes3.json` `images_used`). 이번 실행에서 **새로 만든 클링 이미지 0장** (예산 아젤 45 · NPC 30 중 52장 사용).
- 아젤 7직업·NPC 8명의 리그 테이블·빌드 결과·런타임(NPC 키·talk/gesture·`runtime.farArm/cape`)·갤러리 `?sec=npcpup` 모두 있었다.
- 끊긴 흔적: `npc_marta` 를 마지막에 다시 빌드한 뒤 매니페스트를 다시 쓰지 않아 **`puppet_manifest.js` 의 npc_marta 해시가 옛것**이었다
  (디스크 해시 비교 스크립트로 발견 — 50개 중 1개). `build_all.py azel` 이 끝에 매니페스트를 디스크에서 다시 써서 해결.
  → 교훈: 한 직업만 `build_rig.py` 로 다시 빌드했으면 **반드시 `build_all.py <char>`(또는 write_manifest)로 끝낼 것**.

### 5.2 아젤 몸통 등판의 회색 쐐기 (6직업, 이번에 고침)
- 증상: 점프·낙하·시전처럼 가까운 팔을 들면 **등 뒤(코트 등판과 망토 사이)에 밝은 회색 쐐기**가 보였다(검은 코트라 눈에 띔).
- 원인: 원화에서 **가까운 팔과 코트 등판 사이로 비치는 배경**(담피르 x 561–669, y 981–1285, 1.5만~1.9만 px — 성검사만 없음)이 실루엣에 둘러싸인 구멍이라
  `fig_body`(구멍 메움)가 몸통 부품에 배경색 그대로 남겼다. NPC 에서 쓴 방법(§3.2 ①)이 아젤에는 적용되지 않았던 것.
- 해결: 직업마다 **그 직업 원화 기준으로** 몸통 다각형에서 배경 구멍(행 배경과 거리 < 20, 300px 이상, 몸통 영역에 닿는 것)을 파내 `regions.torso` 를 덮어씀
  (`smooth 0` 윤곽 다각형, 남은 구멍 18–54px). 파기 전 다각형은 `_torsoUncarved` 로 남겨 재실행해도 같은 결과(빌드는 `_` 키를 읽지 않음). 작업 폴더 `carve_azel.py`.
- 참고(리드에게): **카엘 헌터·템플러, 브란 기사 몸통 부품에도 같은 회색 쐐기**가 있다(아틀라스 ui 의 torso 를 마젠타 위에서 보면 왼쪽 아래). 밝은 가죽·은색 판금이라 덜 띌 뿐.
  파이프라인에 넣는다면 build_rig 의 torso 에서 `fig_body & ~(배경색 구멍)` 을 쓰는 것이 근본 해결.

### 5.3 NPC 손짓이 얼굴을 가림 (hero.js NPC 가지, 이번에 고침)
- 하드윈·로크·로크2 는 3/4 원화라 머리가 가까운 어깨보다 앞에 있어, 손짓(a1 −0.45, 얼굴 높이로 손을 앞으로)이 **입·부리를 가리는 자세**로 보였다(“손으로 입 막음”).
- 세 값(−0.45 / −1.15 높이 들기 / +0.1 가슴 앞)과 중간값을 NPC 8명 × 퍼펫·벡터로 비교 → 높이 들기는 팔이 얼굴을 가로지름.
  **−0.1 · 뻗음 0.84(어깨 높이로 손바닥을 내밂)** 가 8명 모두 얼굴을 가리지 않고 인사로 읽혀 기본값으로 바꿈. 벡터 NPC 도 같은 값(자연스러움 확인).
- 값은 `export const NPC_POSE = { gestA, gestR }`(hero.js) 로 내보내 갤러리·QA 에서 바꿔 볼 수 있다. NPC 가지 밖(영웅)에는 영향 없음.

### 5.4 QA 결과 (이번 실행)
- 검증 시트(`sheet.py azel`·`npc`): 부품 테두리·구멍 없음, grip 에 초록 없음, 재질 마스크가 피부·머리카락·손으로 새지 않음, 턴 8방향 라벨이 얼굴 방향과 맞음.
  손 시트 공유 확인 — 원화의 가까운 손이 검은 장갑인 직업은 여명·타천사 포함 6개(성검사만 흰 장갑 → 전용 시트), 노스페라투는 발톱 전용.
- 갤러리(0 페이지 오류): 7직업 `?sec=pup` 전 동작(왼쪽 달리기 포함), `pupatk`(담피르·타천사), `?char=azel&sec=pupw`(6무기 손잡이), `pupeq`(가죽·판금·청판금·마왕 갑주+해진 망토·미스릴·검은 가죽, 날개·후광·박쥐 날개),
