# 블러드 녹턴 3D 판 (리빌드, v2) — 헌장

2026-11-17 시작. 이 문서는 리빌드 작업의 **공통 기준**이다. 세부 설계는 `docs/v2/` 의 다른 문서가 맡고, 서로 부딪치면 이 문서가 이긴다.

## 1. 무엇을 만드나

- 지금 게임(v1)은 옆에서 보는 2D 횡스크롤이다. 리빌드(v2)는 **2D 채색 캐릭터가 입체감 있는 세계를 돌아다니는 액션 게임**이다.
- **이동:** 모든 구간에서 좌우와 앞뒤(화면 안쪽·바깥쪽)로 자유롭게 움직인다. 점프는 그대로 있다.
- **스테이지:** 옆으로 뻗은 구간(횡)과 화면 안쪽으로 뻗은 구간(종)을 오간다.
- **캐릭터:** 영웅·적·보스를 새 시점에 맞게 다시 디자인한다. 소유자가 바라는 느낌은 대형 수렵 액션 게임의 등장인물이다: 반실사 고품질 CG 일러스트, 호감 가는 얼굴과 건강한 체형(7.5–8등신), 밤의 괴물 소재(가죽·비늘·털·뼈·뿔)에 가죽과 단조 금속을 겹친 수렵 장비, 큼직한 상징 무기, 인물마다 뚜렷한 색. 지금보다 밝고 깔끔하게. 특정 게임의 캐릭터·장비·로고를 베끼지 않고 독자 디자인으로 만든다. 셀 애니풍은 쓰지 않는다(소유자가 거절함 — `docs/specs/ART_DECISION.md`).
- **이야기:** v1 이야기를 넓힌다. 방향은 `docs/v2/STORY_OPTIONS.md` 에서 소유자가 고른다.

## 3. 원칙

1. **v1 은 그대로 둔다.** v2 가 대신할 만큼 완성될 때까지 v1 은 늘 플레이할 수 있고 시험이 통과해야 한다. v1 파일은 맡은 작업이 명시한 곳만 고친다.
2. **셸은 다시 쓰지 않는다.** `src/core/`(게임 루프·장면·해상도·입력·가상 패드·저장·소리·UI·에셋), 빌드(`tools/deploy`), APK(`tools/apk`), QA 도구는 폴드에서 검증된 것이라 v2 도 그 위에 올린다. 계약은 `docs/ARCHITECTURE.md` §0–§6.
3. **새로 만드는 것:** 세계·충돌·전투 판정·적 AI·보스·스테이지·그림·이야기 데이터.
4. **먼저 플레이해 보고 넓힌다.** 큰 결정은 폴드에서 직접 해 볼 수 있는 시범판으로 확인한 뒤 굳힌다.
5. 화면 글자는 한국어, 조작은 폴드(터치) 기준으로 먼저 맞춘다.

## 4. 공통 용어 · 좌표

- `x` = 좌우 (오른쪽 +), `z` = 깊이 (화면 안쪽 +, 카메라에서 멀어짐), `y` = 높이 (위 +, 땅 = 0).
- 논리 해상도는 v1 과 같다: 높이 540, 폭 960–1280 (`game.viewW`). 폴드를 편 화면은 폭이 좁고(약 4:3.6) 높이가 넉넉하다.
- **횡 구간** = 길이 x 방향으로 뻗음. **종 구간** = 길이 z 방향으로 뻗음.
- 캐릭터는 2D 그림(빌보드)이고 `facing`(±1)으로 좌우를 뒤집는다. 땅에 그림자를 떨어뜨려 높이·깊이를 읽게 한다.

## 7. 지킬 것

- 서명 키(`tools/android/release.keystore`, `keystore.properties`)는 git 에 올리지 않고 내용도 출력하지 않는다.
- 그림 생성은 Higgsfield `gpt_image_2_5` 만 (`tools/higgsfield/README.md`), 묶음마다 크레딧 상한과 기록(`tools/higgsfield/manifest_<묶음>.json`).
- APK 는 95 MB 이하, 첫 화면 글꼴 500 KB 이하. 새 한글 문구는 글꼴 부분집합 검사(`tools/fonts/build_fonts.py --check`)를 통과해야 한다.
