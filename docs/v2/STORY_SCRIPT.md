# 블러드 녹턴 3D 판 — 첫 출시 대본 (소유자용)

이 글은 `node tools/v2/story_check.mjs` 가 실제 자료(`src/v2/data/`)를 처음부터 끝까지 돌려서 뽑은 것입니다. 손으로 따로 쓴 글이 아니므로 게임에 나오는 글과 한 글자도 다르지 않습니다.

- **두 밤**: 1797년 = 오늘 밤, 1697년 = 그 밤.
- **읽는 법**: 굵은 이름 = 말하는 사람, *기울인 글* = 해설·글씨, `〔 〕` = 화면에 뜨는 알림·목표·단추 안내, (괄호) = 장면 설명(게임에는 글로 나오지 않음).
- 카엘의 괄호 대사는 혼잣말입니다.
- 종탑 안과 배웅의 납골당은 아직 지어지지 않았습니다. 대본은 다 썼고, 지어지면 그대로 붙습니다.

## 덧붙임 6 — 쓰러졌을 때
