## 3. 높음 (6건)

### PS-01 저장 공간 부족 시 세이브 소실 — 수정
- **증상:**
  - 기기 저장 공간이 가득 차면 새 세이브는 메모리에만 남는다.
  - 그런데 불러오기는 예전 기록을 돌려준다.
  - 화면에는 '저장 완료'가 떠서 사용자는 실패를 알 수 없고, 새로 고치면 진행이 사라진다.
- **수정 (`src/core/save.js`, `src/core/game.js`, `src/main.js`):**
  - 쓰기에 실패하면 이후 읽기는 메모리의 최신 기록을 쓴다.
  - 공간이 부족하면 게임이 만든 백업 사본을 지우고 한 번 더 시도한다.
  - 그래도 실패하면 '저장 완료' 대신 두 가지 안내를 띄운다.
    - "저장 공간이 부족해 저장하지 못했습니다"
    - "게임을 닫기 전에 계정 저장이나 저장 코드로 백업하세요"
- **재확인:**
  - 노드 재현에서 수정 전에는 옛 값(골드 100), 수정 후에는 새 값(12345)을 돌려준다.
  - 세이브 시험 65/0, 설정 시험 427/0.

### EC-01 가방이 가득 찬 상태에서 아이템 소멸 — 수정
- **증상:**
  - 가방 300칸이 차면 주운 아이템이 사라진다.
  - '새벽꽃'(k_dawnflower, 유일한 출처)이 사라지면 알베르토 퀘스트를 영원히 끝낼 수 없다.
  - 보스 고유 장비, 상자 내용물, 스테이지 종료 전리품도 같은 식으로 사라진다.
- **수정 (`src/game/world.js`, `inventory.js`, `pickups.js`):**
  - 실제로 가방에 들어갈 때만 아이템을 줍는다.
  - 가방이 차면 아이템은 바닥에 남고, 끌려오지 않으며, 안내는 3초에 한 번만 뜬다.
  - 열쇠·퀘스트·유물 아이템은 300칸 제한에서 뺐다.
  - 받지 못한 아이템은 저장되는 대기열(`progress.lootQueue`)에 넣는다.
    - 대상: 상자·보스 보상, 종료 전리품, 퀘스트 보상, 대사로 받는 아이템
    - 자리가 나면 1초마다 전달한다(마을 포함).
- **재확인:**
  - `test_part2 --static` 에 가방 가득 참 검사를 추가했다.
  - s19 r4 새벽꽃을 한 단계씩 따라가는 시험을 통과했다.
  - 세이브 시험도 통과했다.

### PS-02 웹·PWA 뒤로 가기로 게임이 바로 닫힘 — 수정
- **증상:**
  - 설치형 PWA 에서 뒤로 제스처를 하면 확인 없이 앱이 닫힌다.
  - 가상 스틱이 화면 가장자리에 있어 실수가 잦다.
- **수정 (`src/core/platform.js`):**
  - history 센티널을 두어, 뒤로 가기를 하면 스테이지는 일시정지되고 메뉴는 닫힌다.
  - 타이틀에서는 "뒤로 가기를 한 번 더 누르면 게임을 나갑니다"를 띄운 뒤, 두 번째 뒤로 가기에 나간다.
  - APK 는 이미 네이티브로 처리하고 있으므로 제외했다.
- **재확인:** Playwright 로 스테이지→일시정지, 메뉴 닫기, 타이틀 두 번 뒤로를 확인했다.

### PS-03 APK 서명 키를 조용히 새로 만듦 — 수정
- **증상:**
  - 서명 키 파일이 없으면 `build_apk.sh` 가 경고 없이 새 키를 만든다.
  - 그 APK 는 설치된 앱 위에 업데이트로 설치되지 않는다.
  - 결국 재설치가 필요하고, 재설치하면 세이브가 삭제된다.
- **수정:**
  - 키 파일이 없으면 빌드를 멈춘다. 새 키는 `--new-key` 를 줄 때만 만든다.
  - 서명 전후에 인증서 지문을 공개 파일 `tools/apk/release_cert.sha256` 과 비교한다.
  - 빌드 없이 키만 점검하는 `--check-key` 를 추가했다.
  - 백업·복구 절차를 `docs/RELEASE.md` 에 새로 썼다.
- **재확인:** 키가 없는 경우, 다른 키인 경우, 같은 키인 경우를 각각 시험했다. 기록된 지문은 배포된 APK 와 같다.

### EC-02 「약초 수프」 재료(월하초)를 얻을 수 없음 — 수정
- **증상:** 마르타 퀘스트에 필요한 월하초 5개를 얻을 곳이 게임 어디에도 없어 완료할 수 없다.
- **수정:**
  - 1장 빙의자, 2장 진흙 인간·무덤지기가 월하초를 떨어뜨린다.
  - 1장부터 상점(룩)에서 25G 에 판다.
- **재확인:** 모든 수집 퀘스트 아이템을 해금 장 안에서 얻을 수 있는지 보는 자동 검사를 추가했고 통과했다.

### RU-01 휴대폰 스킬 상세에서 '다음 레벨' 미표시 — 수정
- **증상:**
  - 844×390, 740×360 에서 '다음 레벨' 절이 그려지지 않는다.
  - 740×360 에서는 '현재 효과'도 잘린다.
- **수정 (`src/scenes/menu/tab_skills.js`):**
  - 휴대폰에서는 상세 패널을 작게 줄이고 설명을 스크롤로 보여 준다.
  - 레벨 업이 막혀 있으면 막힌 이유를 표시한다.
- **재확인:**
  - 740×360·844×390·1024×768·1280×720 스크린샷에서 두 절 모두 잘림 없이 보인다.
  - 모바일 메뉴 통합 시험 통과.
